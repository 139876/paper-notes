# 方向 1 · 图像复原谱系：从 DCP 到 DehazeFormer

> [!info] 这是**方向知识脉络**
> 这一轨讲的是**你这个方向的知识地图**：从低层复原一路到高层检测，中间有哪些流派、每个流派解决什么问题、代表作是谁。
> 它**不属于任何一篇论文**——换一篇论文，这张地图依然成立；换一个子方向（比如医学图像分割），地图要重画。
> 📌 底部三个链接区：**先补公共基础**（地基层）→ **本文用在哪**（论文层）→ **同方向其他笔记**（横向串联）。

## 1.1 一句话定位

> **图像复原（Image Restoration）= 把被破坏的图像恢复成"没被破坏时应该是什么样"。**
> 被破坏的方式叫**退化 (degradation)**：雾、噪声、模糊、雨雪、低分辨率。

**在这条线上，"去雾"只是退化的一种。** 但它是这个方向最经典、最有物理模型的入口。

---

## 1.2 三代技术路线

```
第一代：物理模型 + 手工先验（2009–2016）
   DCP → CAP → MSR → COLOR
   关键词：暗通道先验、颜色线先验、大气光估计

第二代：深度 CNN 端到端（2016–2022）
   DehazeNet → GridDehazeNet → AOD-Net → FFA-Net → MSBDN
   关键词：直接回归图像、特征注意、网格/多尺度

第三代：Transformer + 统一模型（2022–2026）
   DehazeFormer → SwinIR / Uformer → All-in-One（雾/雨/雪统一）
   关键词：全局感受野、跨退化统一、prompt
```

### 第一代：物理模型派

| 方法 | 年份 | 核心 idea |
|---|---|---|
| **DCP** (He et al.) | CVPR 2009 | **暗通道先验**：`J_dark ≈ 0` → 暗通道就是透射率 t |
| **CAP** (Zhu et al.) | CVPR 2009 | **颜色线先验**：清晰图局部像素在 RGB 空间近似一条直线 |
| **MSR** (Tan et al.) | CVPR 2010 | 多尺度暗通道 + 颜色线，把暗通道先验推到多尺度 |
| **AOD-Net** (Li et al.) | CVPR 2018 | 把大气模型**重参数化**成 `K(x)`，用公式化网络建模 |

> [!important] DCP 为什么是里程碑
> 它把"去雾"从**拍脑袋的图像处理**变成了**有物理依据的估计问题**：
> 已知 `I(x)`，求 `J(x)` 和 `t(x)`，而 DCP 给了求 t 的捷径。
> 本文第 1 讲讲的就是它 —— **你必须会暗通道先验的推导**。

**这一代的致命伤**：假设太强（"清晰图一定有暗通道"在天空区域经常不成立），且**要手工调参数**（patch size、t 的下限 ω、颜色校正是否开）。

### 第二代：深度 CNN 派

| 方法 | 年份 | 核心 idea |
|---|---|---|
| **DehazeNet** (Zhang et al.) | CVPR 2019 | 用残差公式 `J = R + I − R(G)`，把"估计 t"变成"学一个网络" |
| **GridDehazeNet** (Zheng et al.) | CVPR 2019 | 先在**局部网格**上做大气光估计，再全局重建 |
| **AOD-Net** (Li et al.) | CVPR 2018 | 公式化网络，K(x) = 融合 5 个物理量 |
| **FFA-Net** (Qin et al.) | ECCV 2020 | **特征注意力 + 通道注意力**，把"哪些特征该用"学出来 |
| **MSBDN** (Zhang et al.) | CVPR 2020 | 多尺度**反向**深度网络 |

> [!note] FFA-Net 是本文引用的重点
> 论文在"独立优化"范式里明确点了 **FFA-Net (Qin et al., 2020)**、**MCPNet (Lyu et al., 2024)**、**EENet (Cui et al., 2025)**。
> FFA-Net 的**通道注意力**思想，其实和本文 CFFM 的"逐像素自适应加权"是同一个时代的产物。

### 第三代：Transformer 派

| 方法 | 年份 | 核心 idea |
|---|---|---|
| **DehazeFormer** | CVPR 2023 | 用 **dehazing attention**（跨窗口 + 归一化）替代 MSA，效率更高 |
| **SwinIR / Uformer** | 2021–2022 | 通用图像复原骨干（去噪/超分/去模糊都能用） |
| **All-in-One** (You et al.) | CVPR 2023/2024/2025 | **一个模型同时处理雾/雨/雪/沙**，用 prompt 或 degradation encoder 切换 |

> [!important] "All-in-One" 这条线值得你重点关注
> 它回答的是一个非常实际的问题：**真实场景的天气是混合的**（雾+雨+暗），单一退化模型不够用。
> 这条线现在非常活跃，代表作是 You et al. 的系列工作。

## 1.3 这条线的核心矛盾（也是全文的立身之本）

> [!danger] **像素级的好看 ≠ 任务级的有用**

一篇去雾论文报告 PSNR 从 28 涨到 32，看起来是巨大进步。但把它接在检测器前面，**检测精度可能反而掉**。

原因：

| | 去雾要什么 | 检测要什么 |
|---|---|---|
| 空间平滑性 | **要平滑**（去噪、去伪影） | **要锐利**（小目标边缘） |
| 梯度特征 | 弱梯度更"自然" | 强梯度才能判别 |
| Lipschitz 常数 | 低（L 连续 → 输出平滑） | 高（输出对输入敏感） |

> 🎯 **比喻**
> 去雾要的是**磨砂玻璃**——把划痕和噪点都磨平，看起来柔和高级。
> 检测要的是**放大镜**——把最细微的划痕、裂纹都保留下来。
> **磨砂会毁掉放大镜要用的信息。**

这就是本文第 2 讲（Lipschitz 不匹配）和第 3 讲（多任务梯度冲突）要解决的问题。

## 1.4 两条接线方式（本文的核心分类学）

论文把"图像增强 + 目标检测"的组合方式分成两大类：

### ① 独立优化（Independent / Separate）

```
     雾图 ──→ [现有去雾模型] ──→ 清晰图 ──→ [检测器] ──→ 框
                （训完就冻结）              （在清晰图上训）
```

| 优点 | 缺点 |
|---|---|
| 简单，可直接用任何去雾模型 | **两段各自最优，合起来未必好** |
| 可以换任意去雾器 / 任意检测器 | 去雾损失和检测损失**从不同时优化** |
| 训练开销小 | **低层复原与高层语义冲突时，性能反而下降** |

代表：FFA-Net / MCPNet / EENet + 任意检测器（论文里叫 **Separate** 策略）

### ② 联合优化（Joint / Union）

```
     雾图 ──→ [编码器] ──┬──→ [检测头] ──→ 框 + L_od
                         │
                         └──→ [复原分支] ──→ 约束 L_dh
                    ↑ 反向传播：梯度从 L_od 一直回到编码器
```

| 优点 | 缺点 |
|---|---|
| **端到端优化，两个任务互相促进** | 梯度冲突风险（见 1.3） |
| 复原分支可以**只为检测服务**，不必追求"好看的图" | 训练更复杂、更吃显存 |
| 能利用高层语义指导复原 | 对超参（λ）敏感 |

代表：DSNet、TogetherNet、BAD-Net、IA-YOLO、DFENet、PPNet、**CCFA-Net**

> [!important] 一个关键区分：联合 ≠ 级联
> - **级联**：去雾网络训完**冻结**，只输出图像；检测器看的是**图像**。梯度**不跨接缝**。
> - **联合**：两条分支**端到端连着**，损失一起反向传播，梯度**真的能从检测头回到去雾分支**。
>
> 本文第 3 讲会给你画完整的梯度流向图。

## 1.6 自测题

1. 去雾方法的三代技术路线分别是什么？每一代的核心 idea 是什么？
2. **DCP 的暗通道先验假设是什么？**它在什么情况下会失效？
3. 为什么"**像素级的好看 ≠ 任务级的有用**"？用"磨砂玻璃 vs 放大镜"解释。
4. **"独立优化"和"联合优化"在梯度上有什么本质区别？**
5. 本文 Table 2 里 **Separate 策略全表垫底（最优 44.1）**，而 Direct 策略最优 51.5，联合 54.6。这三个数字说明了什么？

<details>
<summary>👉 自测答案</summary>

**1.**
- **第一代（物理模型）**：DCP / CAP / MSR / AOD-Net。核心是**暗通道先验、颜色线先验**，把去雾变成有物理依据的估计问题。
- **第二代（深度 CNN）**：DehazeNet / GridDehazeNet / FFA-Net / MSBDN。核心是**用网络学透射率 + 特征/通道注意力**。
- **第三代（Transformer）**：DehazeFormer / SwinIR / **All-in-One**。核心是**全局感受野 + 跨退化统一**。

**2.** 假设：**清晰图在每个局部 patch 内，至少有一个通道的像素值接近 0**（`J_dark ≈ 0`）。
失效场景：**大面积天空**（天空本来就接近白，三通道都高）、**过曝区域**。这也是 DCP 需要 `t` 的下限 ω 和暗通道"抠除"后处理的原因。

**3.** 去雾要**平滑**（去噪、去伪影），检测要**锐利**（小目标边缘、强判别响应）。磨砂玻璃会把放大镜要用的划痕、裂纹全磨掉。
**技术上**：去雾网络的映射 Lipschitz 常数低（输出平滑），检测头需要高（对输入敏感）—— 两者放一起会互相拖后腿。

**4.** **独立/级联**：去雾网络训完冻结，只输出**图像**；检测器在清晰图上训练。**梯度不跨接缝**，去雾分支永远看不到检测任务的需求。
**联合**：损失相加后统一反向传播，梯度**真的能从检测头穿过融合模块回到去雾分支的每一个卷积核**。

**5.**
- **Separate 44.1 < Direct 51.5**：说明"先去雾再检测"这条路上，**去雾不但没帮忙，还拖累了**——这正是 1.3 那个矛盾的实证。
- **Direct 51.5（不处理雾，直接在雾图上检测）已经比 Separate 44.1 高 7.4 点**：说明**雾图本身携带的信息并没有丢**，是"先擦玻璃"这个动作把信息擦掉了。
- **Union 54.6**：说明**只要梯度通、且复原被降格为约束**，联合确实能超过"什么都不做"。
- ⚠️ 但也要注意：Direct 51.5 里最好的方法是 NIRNet 49.5 + 别的组合，论文自己也承认**联合的优势建立在"复原分支不拖后腿"的前提上**。

</details>
