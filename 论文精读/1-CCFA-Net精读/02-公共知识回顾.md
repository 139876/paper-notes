## 一、卷积与特征（01-图像与卷积基础）

| 结论 | 复述 |
|---|---|
| 3×3 卷积 | 小方块滑动、逐元素相乘再求和；`in→out` 决定输出**通道**，`3×3` 决定**看多大** |
| padding | 补边 = 给边缘换一种边界假设；直接决定**输出尺寸** |
| 池化 | **不学参数**的降采样；「通道池化 vs 空间池化」是两个不同操作 |
| 感受野 | 一个输出格子**看得见**多大的输入；理论 ≠ 有效 |
| PixelShuffle | **通道重排**的上采样（不是插值）；把 C 通道重排成 H×W |
| 空间注意力图 | 算出一张"哪里重要"的**热力图**；**它是权重不是特征** |

> 🎯 **在 CCFA-Net 里用在哪**：
> 论文的去雾分支是典型的 **Encoder–Decoder + 跳连** 结构：
> 下采样用**池化/步长卷积**，上采样用 **PixelShuffle**（比插值更"锐"）。

## 二、骨干与融合（02-骨干网络与特征融合）

### ResNet
> **让每层只学差值**，深网络才训得动。`∂L/∂x = (∂L/∂H)(∂F/∂x + 1)`，那个 **+1** 就是抗梯度消失的原因。

### FPN
> **Backbone 给多尺度特征，FPN 对齐通道 + 横向连接**，输出多级金字塔。
> **在 neck，不在 head** —— 这是最容易记错的一点。

### 检测器三段式
> **Backbone（看图）→ Neck（多尺度融合）→ Head（下结论）**
> **CCFA-Net 的创新落在 Head 侧（CCDD / CFFM / MFAM）+ 输入侧（去雾）**。

## 三、训练与优化（03-训练与优化）

| 结论 | 复述 |
|---|---|
| 反向传播 vs 梯度下降 | 反向传播**算梯度**（链式法则，从后往前）；梯度下降**更新参数**（沿下坡走一步）。两件事 |
| 损失函数 | 把"好不好"变成**一个可求导的数**；**像素级指标 ≠ 任务级目标** |
| 多任务梯度冲突 | 检测损失和去雾损失**方向可能相反** → 论文用**梯度协调/加权**来化解 |
| SGD + Momentum | `momentum` 让梯度带惯性（平滑、加速）；**lr 要连 momentum 一起看** |

> 🎯 **在 CCFA-Net 里用在哪**：
> `L = L_od + λ·L_dh` 是全文枢纽 —— **λ 就是"检测 vs 去雾"的权重旋钮**，
> λ 太大伤检测，太小雾除不掉。

## 四、检测任务与评测（04-检测任务与评测）

| 结论 | 复述 |
|---|---|
| bbox | 4 个数框住目标；COCO 存 **`[x, y, w, h]`** |
| mAP | IoU 匹配 → TP/FP/FN → 按置信度排序 → **P-R 曲线下面积 = AP** → 类别平均 = mAP |
| 两阶段 vs 单阶段 | 两阶段先出候选框再分类（准、慢）；单阶段密集预测（快、可端到端） |
| 样本分配 | 谁来判"这个位置是不是正样本"（ATSS / TAL） |
| 置信度 ≠ 质量 | 分类自信 **≠** 框得准；TOOD 的 **VarifocalLoss** 让分数反映 IoU 质量 |

> 🎯 **在 CCFA-Net 里用在哪**：
> 论文 baseline 是 **TOOD**（单阶段、anchor-free、TAL 动态样本分配），
> 消融表里的对照是 Faster R-CNN / Cascade R-CNN（两阶段）。

## 五、数据与协议（05-数据标注与协议）

> **COCO 口径**：`mAP@[.5:.95]`，比 VOC 单点 `mAP@.5` 严格得多，**别拿两个口径的数字比**。
> **train/val/test** 三份 + `train_pipeline`/`test_pipeline` 两套（训练随机增强，测试固定）。

## 七、🔥 本篇最容易忘的 5 条（考前默背）

1. **FPN 在 neck，不在 head**。
2. **`L = L_od + λ·L_dh`** —— λ 是"检测 vs 去雾"的唯一旋钮。
3. **COCO mAP@[.5:.95] ≠ VOC mAP@.5**，两个口径不能混。
4. **ResNet 抗梯度消失靠的是那个 `+1`**（恒等捷径）。
5. **论文 24 epoch / 仓库 12 epoch / momentum 0.938 vs 0.9** —— **论文与代码不一致**，复现前必须对账。

## 八、🧪 自测（先合上答案写）

<details>
<summary>Q1：FPN 在哪一层？干什么？</summary>

**Neck**。把 Backbone 的多尺度特征**通道统一 + 横向连接**，输出多级特征给 Head。
</details>

<details>
<summary>Q2：残差连接为什么能解决梯度消失？</summary>

`H = F(x) + x` → 求导得 `∂L/∂x = (∂L/∂H)(∂F/∂x + 1)`，
那个 **+1** 保证梯度至少有一条"恒等通路"原样传回，**不会随深度连乘衰减到 0**。
</details>

<details>
<summary>Q3：CCFA-Net 的 λ 是什么？调大调小分别会怎样？</summary>

`L = L_od + λ·L_dh` 里 **λ 是去雾损失的权重**。
λ 太大 → 优化器优先把雾除干净，**伤检测精度**；λ 太小 → 雾除不掉，**伤检测精度**。
</details>

<details>
<summary>Q4：论文和仓库的训练配置对得上吗？</summary>

**对不上**：论文 24 epoch / milestones [16,22] / momentum 0.938；
仓库 12 epoch / milestones [8,11] / momentum 0.9。
**必须以 config 为准**，或自己跑一遍判定谁对。
</details>

<details>
<summary>Q5：COCO 的 bbox 存的是什么？</summary>

`[x, y, width, height]`，**左上角坐标 + 宽高**，不是 xyxy。
</details>
