### 关键一步：**多源 → 单目标 的划分**

```
每个数据集：
  1. 读入影像 (H, W, C) 与标签 (H, W)
  2. 按标签值分出有效像素
  3. 划分「源域像素集」与「目标域像素集」（通常按区域/斑块切）
  4. 源域：抽训练集 / 验证集
  5. 目标域：**全部像素只做测试**，训练时一个都不给
  6. 每个 (数据集, 源域组合, 目标域) 组合 = 一次实验
```

> ❓ **本文具体用了哪些源域/目标域组合** —— 必须去原文实验设置抄。
> 这类论文通常会写成 "Houston2013: 场景1 → 场景2, 场景3" 这种形式。

### ❌ 论文**没有给**、必须自己定的（复现空缺）

| 超参 | 含义 | 建议怎么定 |
|---|---|---|
| `σ_f` | JVC 高斯核带宽 | 用**中位数启发式**（`σ = median(‖g(f_i)-g(f_j)‖)/√2`），再扫 3~5 个值 |
| `σ_w` | 锚图高斯核带宽 | 同上，或固定 1.0（特征已归一化时） |
| `w^d` | SDP 的目标间隔 | 扫 `{0.1,0.2,0.3}` |
| MLP `g` 结构 | 层数 / 宽度 / 激活 | 先 2 层 MLP，宽度取特征维；或直接搜 |
| `β` 的初值 | L-BFGS 起点 | 全 0 或小随机；凸问题不敏感 |
| L-BFGS 迭代数 | 每步解 β 的代价 | 先试 10~20，看是否收敛 |
| 平衡子集每类样本数 | 训练子集构造 | 每类等量，按原文 Table I 各类样本数取 min |
| `L_COS` 里 `D` | 参与的层数 | 原文 `D=4`（全 4 层） |
| 优化器（网络部分） | — | 原文**没写**是 SGD 还是 Adam → 建议 Adam |

> ⚠️ **重要工程提醒**：
> **MI 的量纲随特征维度增长**（`I` 大约是 `log` 的尺度，乘以维度）。
> 所以 `λ_{jvc}` **必须随 `d` 调整**，否则换个数据集权重完全失效。
> 这是复现这类论文最常踩的坑之一。

## 4️⃣ 训练循环（伪代码）

```python
# ✅ 2026-11-17：按原文式 (1)–(12) + Algorithm 1 重写
# 两个源域各采一个 minibatch；batch_size = 1024，batch 数 = 160

for epoch in range(E):
    # ---- 1) 前向：两个源域 → DBFDF 双分支 → 4 层特征 ----
    f1, y1, l1 = backbone(x_s1)      # f1: {f^d_{s1}}_{d=1..4}
    f2, y2, l2 = backbone(x_s2)
    z1, z2 = mlp_g(f1[D]), mlp_g(f2[D])   # ← 只取第 4 层，过共享 MLP g
    logits = classifier(z1)             # BCE 分类头
    loss_bce = BCE(logits, y1)           # 式 (3)，含类别权重 w_c

    # ---- 2) 骨干的对比/渐进损失（4 层全参与）----
    loss_cos = -sum_d xi(f1[d] · f2[d])          # 式 (1)，xi: 同类 +1 / 异类 -1
    loss_sdp = sum_d (s[d] - s[d+1] - xi*w[d])**2  # 式 (2)

    # ---- 3) JVC：① 先固定 g(f)，用 L-BFGS 解 β̂ --------------------
    #   q(g(f_i), y_i, l_j; β) = Σ_i β_i k(g(f_i), g(f_i)) δ(y,y_i) δ(l,l_i)
    with torch.no_grad():
        G  = cat([z1, z2])                 # 中间域不变特征
        Y  = cat([y1, y2]) ; L = cat([l1, l2])
        K  = gaussian_kernel(G, sigma_f)   # n x n，高斯核 exp(-||·||²/(2σ_f²))
        # 式 (6) 的目标对 β 是凸的 → 用 L-BFGS 求全局最优 β̂
        beta = solve_lbfgs(lambda b: jvc_objective(b, G, Y, L, K))   # → β̂
        q_full = q_of(G, Y, L, beta, K)    # n x n：Q[i][j] = q(g(f_i), y_i, l_j; β̂)
        #        对角线 = 真实配对；非对角线 = 打乱配对（第二项用 l_j）

    # ---- 4) JVC 损失（式 7）：注意第二项的 l_j ----
    loss_jvc = q_full.diag().mean() - exp(q_full - 1).mean()

    # ---- 5) ASI：动态锚点（每轮重算，stop-gradient）+ 锚图正则 ----
    with torch.no_grad():
        for each source j:
            M_j = min(max(2, ceil(n_j/50)), 20)     # 启发式簇数
            C   = KMeans(z_j.detach(), M_j).cluster_centers_
            A   = [argmin ||z_j - mu_m|| for each cluster]   # 式 (9) 锚点
            W   = build_rnn_anchor_graph(A, r=10, sigma_w)  # 式 (10)，互为 r 近邻才连边
    loss_asi = 0.5 * sum_j sum_u sum_z W[u,z] * ||A_u - A_z||^2   # 式 (11)

    # ---- 6) 总损失（式 12）+ 反向 ----
    loss = 1*loss_jvc + 0.05*loss_asi + 3*loss_cos + 10*loss_sdp + 2*loss_bce
    loss.backward(); optimizer.step()   # 只更新 backbone / mlp_g / classifier

    # ---- 7) 目标域评估（eval 阶段，全程不参与梯度）----
    with torch.no_grad():
        z_t = mlp_g(backbone(x_tgt)[D])
        oa = accuracy(classifier(z_t), y_tgt)
```

> [!important] 三个最容易写错的地方
> 1. **JVC 只用第 4 层特征**（`f[D]`），过 MLP `g` 之后才进 JVC；`L_COS` / `L_SDP` 才是 4 层全用。
> 2. **`β` 用 L-BFGS 求、`g` 用梯度下降求**，是两段式；不要用同一个 optimizer。
> 3. **第二项是 `l_j` 不是 `l_i`** —— 代码里就是 `q_full` 的**非对角线**求平均。
>
> [!note] 效率提醒
> `q_full` 是 `n×n` 矩阵，`n` = 两个域的 batch 合计 = **2048**（batch_size 1024 × 2 域）。
> 2048² ≈ **4.2M** 个元素，每个元素一次高斯核求值 → 这一步是**显存和时间的瓶颈**。
> 实操上建议：
> - `K` 矩阵**提前算好并缓存**（只依赖 `G` 和 `σ_f`）；
> - 用 `float32` / `half` 存 `q_full`；
> - L-BFGS 迭代数先设小（如 5~10），观察是否稳定；
> - 若显存吃紧，**对 `n` 做随机子采样**（如取 512），这属于合理近似，但要在报告里写明。

## 5️⃣ 复现 checklist（逐条打勾）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 目标域**真的没进过训练** | 训练循环里 `x_tgt` 只出现在 `no_grad` 的评估块 |
| 2 | 目标域**没进过聚类** | `KMeans` 的输入只含源域特征 |
| 3 | 锚点每轮**重算**（不是固定） | 打日志打印前两轮锚点坐标，应当不同 |
| 4 | KDE 带宽**不是默认值** | 至少扫 3 个 `h` 看 OA 曲线 |
| 5 | **MI 量纲**已处理 | 特征先归一化；`λ` 随 `d` 调整 |
| 6 | L-BFGS 部分**闭循环**正确 | 一次 LBFGS step 内要重新计算 loss 并 `backward` |
| 7 | **多种子**跑完 | 至少 3 个种子，报均值 ± std |
| 8 | 消融**四组**都跑 | baseline / +JVC / +ASI / +DBFDF / 全上 |
| 9 | 结果**落盘 JSON** | 表格数字可由 JSON 一键复现 |
| 10 | 与**至少一个经典基线**对比 | CORAL / MMD / DANN 至少选一个 |

## 6️⃣ 常见坑（提前知道，少走弯路）

| 坑 | 症状 | 解法 |
|---|---|---|
| **目标域泄漏** | 评估时把目标域标签用于选模型 | 选模型只能用源域验证集 |
| **KDE 高维失效** | 带宽怎么调 OA 都不动 | 先降维（PCA）再估；或换 MINE |
| **MI 量纲爆炸** | 换个数据集 `λ` 就失效 | 归一化 + 随 `d` 调 `λ` |
| **k-means 慢** | 训练慢到不可接受 | mini-batch KMeans；每 N 步更新一次锚点 |
| **L-BFGS 不收敛** | 闭循环里 loss 不降 | 检查 `create_graph` / 手动 `closure` |
| **"平均提升"陷阱** | 某组合大涨、某组合大跌 | 逐组合记录，别只看均值 |
