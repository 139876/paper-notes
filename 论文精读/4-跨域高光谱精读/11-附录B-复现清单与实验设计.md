## 2️⃣ 数据准备

| 数据集 | 原始文件 | 常用处理 |
|---|---|---|
| Houston 2013 | `.mat`（标签）+ `.hdr`（影像） | 去坏波段 → ~120 通道 |
| Pavia University | `.mat`（含 img + gt） | 103 通道，保留 |
| Indian Pines | `.mat`（img + gt） | 去噪 + 去坏波段 → ~46 通道 |

### 关键一步：**多源 → 单目标 的划分**

```
每个数据集：
  1. 读入影像 (H, W, C) 与标签 (H, W)
  2. 按标签值分出有效像素
  3. 划分「源域像素集」与「目标域像素集」（通常按区域/斑块切）
  4. 源域：抽训练集 / 验证集
  5. 目标域：**全部像素只做测试**，训练时一个都不给
  6. 每个 (数据集, 源域组合, 目标域) 组合 = 一次实验
```

> ❓ **本文具体用了哪些源域/目标域组合** —— 必须去原文实验设置抄。
> 这类论文通常会写成 "Houston2013: 场景1 → 场景2, 场景3" 这种形式。

## 3️⃣ 需要你自己定的超参（论文待补）

| 超参 | 含义 | 常见取值 / 怎么定 |
|---|---|---|
| `K` | 锚点个数 | 类别数的整数倍？先扫一遍 |
| 带宽 `h` | KDE 带宽 | Scott's rule / Silverman，或扫参 |
| `λ_{jvc}` | JVC 权重 | 网格搜，但注意量纲（MI 的尺度随 `d` 变） |
| `λ_{asi}` | ASI 权重 | 同上 |
| `λ_{cos}, λ_{sdp}` | 余弦 / SDP 权重 | 同上 |
| `q` 网络 | 变分分布参数化 | 几层 MLP + softmax |
| lr / batch / epochs | 常规 | — |
| 优化器 | SGD/Adam（网络部分）+ **L-BFGS**（MI 部分） | 两套优化器 |

> ⚠️ **重要工程提醒**：
> **MI 的量纲随特征维度增长**（`I` 大约是 `log` 的尺度，乘以维度）。
> 所以 `λ_{jvc}` **必须随 `d` 调整**，否则换个数据集权重完全失效。
> 这是复现这类论文最常踩的坑之一。

## 4️⃣ 训练循环（伪代码）

```python
for epoch in range(E):
    # ---- 1) 前向：源域特征 ----
    f_src, y_src = backbone(x_src)          # DBFDF 双分支
    logits = classifier(f_src)
    loss_cls = CE(logits, y_src)

    # ---- 2) 动态锚点（每轮重算，stop-gradient）----
    C = KMeans(f_src.detach()).cluster_centers_     # K x d
    A = build_anchor_graph(C)                        # K x K（压缩表示）

    # ---- 3) JVC：联合变量分布对齐 + MI 最小化 ----
    z_joint = (f_src, y_src_onehot)                  # 联合变量
    kde_src = KDE(z_joint) ; kde_tgt_like = ...      # 多源分布
    loss_align = distribution_alignment(kde_src, kde_tgt_like)
    loss_mi   = mi_variational_lower_bound(f_src, domain_label)
    loss_jvc  = loss_align + loss_mi

    # ---- 4) ASI：结构一致性 ----
    loss_asi = structure_consistency(f_src, C, A) + sdp_loss(...)

    # ---- 5) 总损失 + 反向 ----
    loss = loss_cls + lam_jvc*loss_jvc + lam_asi*loss_asi + ...
    loss.backward(); optimizer.step()

    # ---- 6) 目标域评估（只在 eval 阶段，全程不参与梯度）----
    with torch.no_grad():
        f_tgt = backbone(x_tgt)
        oa = accuracy(classifier(f_tgt), y_tgt)
```

## 5️⃣ 复现 checklist（逐条打勾）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 目标域**真的没进过训练** | 训练循环里 `x_tgt` 只出现在 `no_grad` 的评估块 |
| 2 | 目标域**没进过聚类** | `KMeans` 的输入只含源域特征 |
| 3 | 锚点每轮**重算**（不是固定） | 打日志打印前两轮锚点坐标，应当不同 |
| 4 | KDE 带宽**不是默认值** | 至少扫 3 个 `h` 看 OA 曲线 |
| 5 | **MI 量纲**已处理 | 特征先归一化；`λ` 随 `d` 调整 |
| 6 | L-BFGS 部分**闭循环**正确 | 一次 LBFGS step 内要重新计算 loss 并 `backward` |
| 7 | **多种子**跑完 | 至少 3 个种子，报均值 ± std |
| 8 | 消融**四组**都跑 | baseline / +JVC / +ASI / +DBFDF / 全上 |
| 9 | 结果**落盘 JSON** | 表格数字可由 JSON 一键复现 |
| 10 | 与**至少一个经典基线**对比 | CORAL / MMD / DANN 至少选一个 |

## 6️⃣ 常见坑（提前知道，少走弯路）

| 坑 | 症状 | 解法 |
|---|---|---|
| **目标域泄漏** | 评估时把目标域标签用于选模型 | 选模型只能用源域验证集 |
| **KDE 高维失效** | 带宽怎么调 OA 都不动 | 先降维（PCA）再估；或换 MINE |
| **MI 量纲爆炸** | 换个数据集 `λ` 就失效 | 归一化 + 随 `d` 调 `λ` |
| **k-means 慢** | 训练慢到不可接受 | mini-batch KMeans；每 N 步更新一次锚点 |
| **L-BFGS 不收敛** | 闭循环里 loss 不降 | 检查 `create_graph` / 手动 `closure` |
| **"平均提升"陷阱** | 某组合大涨、某组合大跌 | 逐组合记录，别只看均值 |
