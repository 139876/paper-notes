## 8.2 先讲真本事（别只挑刺）

| # | 优点 | 说明 |
|---|---|---|
| 1 | **问题定位准** | 抓住了现有 DG 方法的**共同盲区**：局部两两对齐 ≠ 全局分布约束；且没人系统讨论"对齐会破坏几何结构" |
| 2 | **三个模块分工清晰、互补** | JVC（分布）/ ASI（结构）/ DBFDF（骨干），三块各管一件事，消融应该能证明"缺一不可" |
| 3 | **MI 最小化替代对抗** | 少一个判别器网络，训练更稳、更简单，是**可以借用的工程技巧**（即使你不做高光谱） |
| 4 | **锚点动态化** | 摆脱了"锚点依赖源域标注"和"锚点过时"两个常见坑 |
| 5 | **关注稳定性** | 报 std 下降而不只报均值，说明作者理解**泛化 = 稳**，不是刷分 |

## 8.3 软肋（批判要具体，别泛泛而谈）

### 批评 ① · 动态簇锚点的三个隐性问题

| 问题 | 说明 |
|---|---|
| **不可微** | k-means 没有梯度，锚点拿不到梯度信号，只能当"每轮重算的中间量"（stop-gradient）。**锚点本身不保证是最优的** |
| **计算开销** | 每轮迭代都要对所有源域特征做一次 k-means → **训练变慢**，且特征越多越贵 |
| **超参 K** | 锚点个数 `K` 怎么定？类别数？类别数的倍数？还是搜出来？**论文未给，待补** |

> **更狠的一层追问**：
> 如果锚点来自 k-means，而 k-means 的簇在**域偏移严重时本来就对不齐**（A 域的"草地"簇和 B 域的"草地"簇是两个不同的簇），
> 那"结构不变"这个目标本身就有隐患 —— **参照系本身可能是错的**。

### 批评 ② · KDE 在高维下的困境

- 高光谱特征维度高（几十到几百维）；
- **高维 KDE 会遭遇维度灾难**：样本点之间的距离趋于相同，密度估计失去分辨力；
- MI 的变分下界本身也**有估计偏差**（下界不紧）。

> **追问**：那 JVC 的"全局分布约束"在高维下**真的成立吗**？还是只是"在一个被平滑过的近似分布上对齐"？

### 批评 ③ · 只在三个像素级分类数据集上验证

- 三个数据集都是**像素级场景分类**；
- **没有真实下游任务**（作物产量估算、矿物识别、异常检测）；
- 没有跨**传感器谱段不同**的极端情况（Houston 是 CASI、Pavia 是 ROSIS、Indian Pines 是 AVIRIS —— 三者波段数都不同，这确实考验跨传感器能力，但仍是"同一场景类型"）。

### 批评 ④ · 提升幅度需要显著性检验

- OA 平均 +1.74%、std 降 11.25% —— **有没有做多次重复的显著性检验**？
- 不同随机种子 / 不同划分下的结果差异，是否大于 1.74%？
- **待补原文**。

### 批评 ⑤ · "卷积+相减"的双重身份容易造成阅读混淆

- 摘要批评现有方法"依赖隐式卷积-相减式对齐"；
- 本文自己的 DBFDF **也用隐式卷积 + 相减**（据专利）。

**这不是错误，但作者应该在正文里明确说清楚**：批评的是"**把它当对齐手段**"，自己用的是"**把它当特征分离机制**"。
> **读者体验上的问题**：不读专利只读论文的人，**很容易觉得自相矛盾**。

### 批评 ⑥ · 压缩锚图的具体形式缺失（信息层面）

- 这是本文的一个**技术核心**，但目前**只能从专利反推**；
- 论文正文里如果写得含糊，**复现难度会很高**。

## 8.4 与经典方法的关系表（放在这里复习）

| 方法 | 对齐什么 | 全局性 | 保结构 | 需要额外网络 |
|---|---|---|---|---|
| CORAL | 二阶协方差 | 中 | 隐式 | 否 |
| MMD | 边缘分布（核） | 中 | 否 | 否 |
| Instance Norm / AdaBN | 统计量 | 弱 | 否 | 否 |
| DANN（对抗） | 域标签不可分 | 强 | **否** | **是**（判别器） |
| 隐式卷积-相减（被批评的对象） | 两两差异 | **弱** | **否** | 否 |
| **JVC** | 联合变量分布 + MI | **强** | 否 | 否 |
| **ASI** | — | — | **是** | 否 |
| **JVC + ASI + DBFDF** | 分布 + 结构 + 骨干 | **强** | **是** | 否 |

## 8.5 可做选题（每个都写清：现状 → 缺口 → 怎么做 → 怎么验证）

### 选题 1 · 高光谱域不变表征 → **迁移到 UAV 检测**

| 项 | 内容 |
|---|---|
| 现状 | ④ 解决的是**像素级分类**的域泛化；① 解决的是**UAV 检测**的雾域协同 |
| 缺口 | 没人把"域不变特征 + 几何结构保持"这套搬到**检测任务**上（检测要的是"可分 + 尺度不变 + 位置敏感"，比分类多好几层要求） |
| 怎么做 | 用 JVC 约束检测头的**分类分支特征**；用 ASI 约束**回归分支**的特征几何结构（框的相对位置关系本身就是几何结构！） |
| 怎么验证 | HazyDet + 合成到真实的雾域划分，看 mAP 与跨场景 std |

> 📌 这一条和你的主方向（CCFA-Net）**直接接得上**，见 [[paper-notes/论文精读/00-总索引-四篇论文|四篇论文总索引]] 里的选题线索。

### 选题 2 · 锚点的"参照系正确性"问题

| 项 | 内容 |
|---|---|
| 现状 | 动态 k-means 选锚点，但 k-means 在强域偏移下簇会错位 |
| 缺口 | **没人研究"锚点本身错了会怎样"** |
| 怎么做 | ① 先做**锚点纯度实验**（锚点与真实类别的对应率）；② 设计**域一致的锚点选择**（用各域特征**联合**聚类，而不是每域各聚各的）；③ 引入**锚点可靠性权重** |
| 怎么验证 | 在**极强域偏移**（跨传感器波段差很大）下，比较三种锚点选择方式的 OA / std / 锚点纯度 |

### 选题 3 · 高维 MI 估计器

| 项 | 内容 |
|---|---|
| 现状 | 用 KDE + 变分下界估 MI |
| 缺口 | 高维下 KDE 灾难、变分下界有偏 |
| 怎么做 | 换成 **MINE**（对比式 MI 估计）、**CLUB**、或先降维再估；做**估计器对照实验** |
| 怎么验证 | 报告不同估计器下 JVC 的**实际对齐质量**与最终 OA |

### 选题 4 · DG + 测试时适应（TTA）混合

| 项 | 内容 |
|---|---|
| 现状 | ④ 是纯 DG（测试时目标域完全不可见）；现实里通常能拿到少量目标域数据 |
| 缺口 | DG 与 TTA 的**结合策略**在高光谱上没人系统做 |
| 怎么做 | DG 学域不变先验 → TTA 阶段用少量目标域样本做轻量微调 / 熵最小化 |
| 怎么验证 | 目标域可用样本数 ∈ {0, 1%, 5%, 10%} 的曲线 |

### 选题 5 · 联合学习里的"约束冲突"（**最贴近你的方向**）

| 项 | 内容 |
|---|---|
| 现状 | ① CCFA-Net 论文自己就指出：去雾网络 **Lipschitz 连续性低**（平滑映射），检测器**高**（依赖判别性响应），两者**不匹配会破坏整体框架**。④ 恰好提供了"**既要对齐分布，又要保住判别性**"的思路 |
| 缺口 | ① 只在特征层面用 CFFM 融合，**没有显式的分布/结构约束** |
| 怎么做 | 在 ① 的 CFFM 之后加一个 **MI 最小化头**（域 = 雾域/净域）+ **几何结构保持约束**（雾域与净域特征的类别簇结构一致） |
| 怎么验证 | HazyDet 上 mAP 提升 + 合成雾→真实雾的**掉点幅度收窄**（这是 ① 最大的痛点：54.6 → 28.7） |

### 选题 6 · 计算效率：动态聚类的代价

| 项 | 内容 |
|---|---|
| 现状 | 每轮 k-means，慢 |
| 缺口 | 没人算过这笔账 |
| 怎么做 | **在线 k-means**（mini-batch）/ **锚点复用**（每 N 步更新一次）/ 锚点**动量更新** |
| 怎么验证 | 报**训练时间**和 OA 的 trade-off 曲线 |

## 8.6 答辩问题预案（可能会被问的）

| # | 问题 | 回答要点 |
|---|---|---|
| 1 | 你的方法和 DANN 比，优势在哪？ | DANN 要额外判别器 + 对抗训练不稳；本文用 MI 下界，**少一个网络**、更稳；但 DANN 的对抗信号更强 |
| 2 | MI 最小化和域判别器 + 熵最大化（SHOT）有什么区别？ | SHOT 是**单域**的源域假设（目标域判别器 + 信息最大化）；本文是**多源 DG**，目标是跨域不变 + 保持几何结构 |
| 3 | 目标域完全不可见，那你的"锚点"从哪来？ | 全部来自**源域特征的 k-means**（多源合并后聚类），不涉及目标域 |
| 4 | +1.74% 有统计显著性吗？ | ⚠️ **待补原文**；从方法上说应报多种子均值±std 并做检验 |
| 5 | 为什么不直接用 CORAL/MMD？ | 它们只对齐边缘分布/二阶矩，不管联合变量、也不保几何结构；且 MI 项提供了比对抗更稳的域不变信号 |
| 6 | 你们的骨干也用"隐式卷积+相减"，和你们批评的方法有何不同？ | 批评的是**当对齐手段用**；本文是**当特征分离机制用**，并额外施加了 JVC 的全局分布约束 |
| 7 | 如果锚点选错了，ASI 会不会反而有害？ | 会 —— 这是我的**批评 ①**，也是选题 2 的动机 |

## 8.7 自测题

> [!question]- 1. 用一句话说明本文和"现有 DG 方法"的根本差别。
> **答案**：现有方法靠**隐式卷积-相减**做**局部两两对齐**（缺全局约束、且会破坏几何结构）；本文用 **JVC** 施加**联合变量层面的全局分布约束** + **MI 最小化**，用 **ASI** 显式**保持几何流形结构**，用 **DBFDF** 把域特有与域共性**解耦**后再融合。

> [!question]- 2. 为什么"对齐全局分布"和"保住判别性"会冲突？
> **答案**：对齐得越彻底，两个域的特征分布越像 → 但类别簇之间的**相对结构**（间距、形状）也越容易被压平 → 类间可分性下降。这就是摘要说的 "compromising the discriminability"。**对齐是"让两个域一样"，判别性要的是"类和类之间差别大"，后者可能被前者破坏。**

> [!question]- 3. 本文最值得"借"到自己方向上的是哪一个点？
> **答案**：**MI 最小化替代对抗**（少一个网络、训练更稳）和**"对齐 + 保结构"必须联合优化**的思路。**在检测任务里，对齐会破坏判别性这个问题更严重**（检测要的是强判别响应），CCFA-Net 自己也指出了 Lipschitz 失配问题，所以 JVC/ASI 的思路非常适合移植过去。

> [!question]- 4. 动态簇锚点的最大隐患是什么？
> **答案**：**参照系本身可能是错的** —— 强域偏移下 k-means 把"同一类"分到不同簇、把"不同类"分到同一簇，那么"结构不变"这个目标就是在把错误结构保持下去。其次是**不可微**（拿不到梯度）和**每轮重算的开销**。

> [!question]- 5. 为什么"局部两两对齐"不能推出"全局对齐"？
> **答案**：两两相减只保证**每一对域之间的差异**是对的，不保证**整体分布形状**一致。极端情况下每个点都相对自己的邻居"挪到位了"，但整体分布的形状、支撑集、密度峰数可能完全对不上。**这正是 JVC 要补的"全局分布约束"。**
