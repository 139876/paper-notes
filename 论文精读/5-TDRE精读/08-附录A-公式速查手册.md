## A.1 全部 14 条公式

### 阶段 ① 退化感知（Clear-Sky Perceptron）· 参数 273

**式 (1)** 🟡 特征提取

$$
F_m = f_{\text{ReLU}}\Bigl( f_{\text{BN}}\bigl( f_{\text{Conv1}}( I_{\text{Input}} ) \bigr) \Bigr)
$$

- `Conv1`：3×3 卷积（原文明确）
- ⚠️ **输入/输出通道数原文未给**

**式 (2)** 🟡 清晰置信度

$$
S_{ca} = f_{\text{Sigmoid}}\Bigl( f_{\text{fc2}}\bigl( f_{\text{ReLU}}\bigl( f_{\text{fc1}}\bigl( f_{\text{Pooling}}( F_m ) \bigr) \bigr) \bigr) \Bigr)
$$

- `Pooling`：全局池化（🔴 原文只写 "the pooling layer"，**没说是全局还是别的**；但从"全图判清晰"的任务看**几乎必然是全局池化**）
- **阈值 0.5**：Sca > 0.5 → 判定清晰 → **硬旁路**

**式 (3)** 🟡 第三阶段输出

$$
I_E = f_{\text{Conv3}}\Bigl( f_{\text{ReLU}}\bigl( f_{\text{Conv2}}( I_R ) \bigr) \Bigr)
$$

- `Conv2`、`Conv3` 原文明确是 **3×3 卷积**
- ⚠️ 但我按 3×3 + 3×3 枚举**找不到 251 的解**；
  唯一较合理的组合是 **`Conv2(3→8, 3×3)` + `Conv3(8→3, 1×1)` = 224 + 27 = 251**（🔴 我的推测）

---

### 阶段 ② 条件专属复原（DR-MoE）· 参数 2406

**式 (4)** 🟡 共享预处理

$$
F_P = f_{\text{ReLU}}\Bigl( f_{\text{Conv5}}\bigl( f_{\text{ReLU}}( f_{\text{Conv4}}( I_D ) ) \bigr) \Bigr)
$$

**式 (5)** 🟡 门控权重

$$
V_P = f_{\text{softmax}}\Bigl( f_{\text{fc3}}\bigl( f_{\text{flatten}}\bigl( f_{\text{Pooling}}( F_P ) \bigr) \bigr) \Bigr)
$$

- `V_P` 三分量之和 = 1（雾 / 沙尘 / 低照）
- ⚠️ **图像级**（全局池化后输出一个向量）
- ⚠️ **门控 CE 的类别数与标签定义原文未说**

**式 (6)** 🟢 专家多尺度融合

$$
F_E^i = f_{\text{cat}}\Bigl( f_{\text{Conv6}}\bigl( f_{\text{ReLU}}( F_P ) \bigr),\;
                          f_{\text{Conv7}}\bigl( f_{\text{ReLU}}( F_P ) \bigr),\;
                          f_{\text{Conv8}}\bigl( f_{\text{ReLU}}( F_P ) \bigr) \Bigr)
$$

- **核大小原文明确**：Conv6 = 3×3、Conv7 = 5×5、Conv8 = 7×7
- 三个专家 i ∈ {fog, dust, lowlight}
- `cat` 沿**通道维**

**式 (7)** 🟡 加权融合

$$
F_{\text{fusion}} = f_{\text{Conv9}}\left( \sum_{i=1}^{3} F_E^i \cdot V_P^{i} \right)
$$

- **Top-3 routing**：训练与推理都**同时激活全部 3 个专家**（原文明确）
- `Conv9` 把 3b 通道压回 c 通道（🔴 通道数推断）

**式 (8)** 🟡 大气先验

$$
I_R = f_{\text{ReLU}}\Bigl( \bigl( F_{\text{fusion}} - I_D \bigr) \odot F_{\text{fusion}} + b \Bigr), \qquad b = 1
$$

- **⊙** = 逐元素乘
- **b = 1 原文明确**（"empirically set to 1 in this work"）
- ⚠️ 原文称其为 "atmospheric transfer equation"，但**正文没有给出从物理模型到式 (8) 的推导**
- 🔴 我的解读：`(F_fusion − I_D)` ≈ 退化残差，`⊙ F_fusion` 做**内容自适应调制**，b 提供中性基准

---

### 阶段 ③ 检测导向增强 · 参数 251

**式 (9)** 🟢 感知器损失

$$
L_{CSP} = \frac{1}{N} \sum_{i=1}^{N} \Bigl[ - y_i \cdot \ln\bigl( \sigma(\hat{y}_i) \bigr) - (1-y_i) \cdot \ln\bigl( 1 - \sigma(\hat{y}_i) \bigr) \Bigr]
$$

- 标准 BCE；真值标签 `y_i` ∈ {0,1}（1 = 清晰）

**式 (10)–(13)** 🟢 多空间复原损失

$$
L_{RGB} = f_{L2}\bigl( I_R,\; I_C \bigr)
$$

$$
L_{HSV} = f_{L2}\bigl( f_{HSV}( I_R ),\; f_{HSV}( I_C ) \bigr)
$$

$$
L_{LAB} = f_{L2}\bigl( f_{LAB}( I_R ),\; f_{LAB}( I_C ) \bigr)
$$

$$
L_{MSR} = L_{RGB} + L_{HSV} + L_{LAB}
$$

- `I_C` = 同一张图的**清晰版本**（CAD-ADD 配对提供）
- 三个损失**等权直接相加**（原文没给权重）

**式 (14)** 🟢 检测导向增强损失 ★

$$
L_{DE} = f_{L2}\bigl( f_{\text{Mask}}( I_E ),\; f_{\text{Mask}}( I_C ) \bigr)
$$

- `Mask` 由 **GT 检测框**生成
- **只在训练时使用**；推理时不需要任何标注

## A.2 三阶段损失汇总（论文原文表述）

| 阶段 | 损失 | 组成 | 冻结 |
|---|---|---|---|
| ① | `L_CSP` | BCE | — |
| ② | 门控 CE **+** `L_MSR` | CE + (RGB + HSV + LAB) | ① 冻结 |
| ③ | `L_DE` | 掩码 L2 | ①② 冻结 |

> ⚠️ **权重全部未给**：门控 CE 与 `L_MSR` 的比值、`L_DE` 自身的权重、是否还有 `L_stage2 + λ·L_DE` 之类的组合 —— **论文一个字都没提**。

## A.3 参数账（用来验算你的实现）

### 通用公式

| 算子 | 参数量 |
|---|---|
| 3×3 卷积（i→o，带 bias） | 9·i·o + o |
| 5×5 卷积（i→o，带 bias） | 25·i·o + o |
| 7×7 卷积（i→o，带 bias） | 49·i·o + o |
| BatchNorm（o 通道） | 2·o |
| 全连接（i→o，带 bias） | i·o + o |
| 拼接（cat） | **0**（只是通道数相加） |
| 逐元素乘 / 加（⊙、+） | **0** |

### 论文声称的分阶段参数

| 阶段 | 论文参数 | 关键结构 |
|---|---|---|
| ① Clear-Sky Perceptron | **273** | Conv1(3×3) + BN + fc1 + fc2 |
| ② DR-MoE | **2406** | Conv4 + Conv5 + Conv6(3×3) + Conv7(5×5) + Conv8(7×7) + Conv9 |
| ③ Enhancement | **251** | Conv2(3×3) + Conv3(3×3) |
| **合计** | **2930（2.93 K）** | |

### 🔴 我的穷举反推结果（**推测，非原文**）

> 我用标准结构写了脚本穷举，结论是：**参数量总数是"欠定"约束，反推不出唯一结构。**

| 阶段 | 目标 | 能凑上的解数 | 一个较合理的候选 |
|---|---|---|---|
| ① | 273 | 有限多组 | `Conv1(3→8, 1×1)` + `BN(8)` + `fc1(8→25)` + `fc2(25→1)`（fc 无 bias）= 32+16+200+25 = **273** ✓ |
| ② | 2406 | **1681 组** | `Conv4(3→21)` 588 + `Conv5(21→3)` 570 + `Conv6(3→3,3×3)` 84 + `Conv7(3→3,5×5)` 228 + `Conv8(3→3,7×7)` 444 + `Conv9(9→6)` 492 = **2406** ✓ |
| ③ | 251 | 有限多组 | `Conv2(3→8, 3×3)` 224 + `Conv3(8→3, 1×1)` 27 = **251** ✓ |

> [!important] 这条结论本身就是个方法论
> **参数量总数只能当"验算器"，不能当"设计器"。**
> 写完实现后 `sum(p.numel() for p in model.parameters())` 对一下 273 / 2406 / 251，
> **差得远 = 结构理解错了**；对上了 = 大方向对。
> 但**要确定唯一结构，只能读代码**。

## A.4 ★ 复现空缺清单（论文没给的，你必须自己定或查代码）

### 🔴 数据与协议（最致命）

| # | 缺什么 | 影响 | 怎么办 |
|---|---|---|---|
| 1 | **退化合成参数**（雾浓度模型、沙尘强度、光照衰减曲线） | **决定性** —— 复现不出训练分布 | 查代码；查不到就自己复刻并注明 |

| 6 | **epoch / 迭代步数** | 中 | 读代码或自行设定 |
| 7 | **weight decay** | 中 | 读代码 |
| 8 | **学习率 schedule**（2e-3→2e-5 的具体形式：step / cosine / exp？） | 中 | 读代码 |
| 9 | **门控 CE 的权重 λ** 与 **类别数** | 中 | 读代码 |
| 10 | **`L_DE` 的权重**、是否与 `L_MSR` 组合 | 中 | 读代码 |
| 11 | **掩码细节**：外扩比例、归一化、无框图处理 | 中 | 自行设计并注明 |

| # | 位置 | 问题 |

| 1 | 3.1 节 | 写 *"threshold sensitivity analysis in **Table 6**"*，实际在 **Table 7**（Table 6 是换检测器） |

| 3 | 式 (8) | 冠名 "atmospheric transfer equation"，但**正文无推导** |
