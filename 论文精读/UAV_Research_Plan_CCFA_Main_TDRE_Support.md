# 近期科研工作计划

# 研究方向与基线体系（最终调整版）

> **当前确定的研究主题：雾天无人机小目标检测 + 跨场景域泛化。**
 **CCFA-Net 是核心任务基线，TDRE 是重要辅助对比基线**。

## A. 最终研究定位

**拟研究方向：** 面向雾天无人机小目标检测的可靠性引导跨场景域泛化。

**拟解决的核心问题：**

在雾天无人机图像中，去雾或恢复特征不一定真实、稳定，也不一定对小目标检测有益。当测试场景的地点、背景、成像条件或雾条件发生变化时，模型可能过度依赖特定场景纹理或不可靠的恢复细节。研究拟探索如何估计恢复特征的任务可靠性，并利用可靠性指导原始雾图与恢复特征的融合，以及源域训练下的类别—尺度条件泛化。

**研究主线：**

1. 诊断去雾特征在不同雾强度、目标类别和目标尺度下的可靠性。
2. 研究可靠性引导的原始雾图—恢复特征选择性融合，减少伪影和错误恢复对检测的干扰。
3. 研究可靠性约束的类别—尺度条件源域泛化方法，并在严格未见场景测试协议下验证。

本研究不把“再设计一个普通去雾网络”“普通原图/去雾图融合”或“简单增加多尺度注意力”作为核心创新。上述方向已有相关工作，需要在已有方法基础上明确新的问题和可验证的贡献。

## B. 基线选择：为什么 CCFA-Net 是核心任务基线？

### B.1 核心任务基线：CCFA-Net

**论文：** *CCFA-Net: Cross-domain Collaborative and Foreground-aware for UAV Object Detection in Hazy Scenes*

- 期刊：ISPRS Journal of Photogrammetry and Remote Sensing, 2026, Vol. 236, pp. 552–568
- DOI：https://doi.org/10.1016/j.isprsjprs.2026.04.020
- 代码：https://github.com/XFCV26/CCFA-Net

**选择理由：**

1. **任务对象最接近。** CCFA-Net 直接面向雾天无人机目标检测，而本研究已明确收窄到雾天 UAV 小目标检测，不再以多天气航拍增强为主要研究对象。
2. **已有去雾—检测协同机制。** 它不是简单地先去雾再检测，而是研究原始雾图和恢复特征如何协同用于检测。因此，适合作为检验“可靠性引导融合是否真正带来额外收益”的直接比较对象。
3. **已考虑前景与多尺度目标。** 本研究不能把普通多尺度特征提取或前景增强直接包装成新贡献，而应进一步研究不同类别、不同尺度目标的恢复可靠性及其跨场景稳定性。
4. **便于明确创新边界。** 在 CCFA-Net 基础上，研究重点可以从“如何协同融合”推进到“融合信息是否可靠，以及这种可靠性如何帮助未见场景泛化”。

**论文报告结果的使用边界：** CCFA-Net 论文报告在 HazyDet 上取得 mAP 54.6%，比其报告的 DeCoDet 高 3.1 个百分点。该数值只能作为原论文结果背景，不能直接与本研究复现实验比较；必须统一数据划分、检测器、类别映射、输入分辨率和训练设置后再作公平比较。

### B.2 重要辅助对比基线：TDRE

**论文：** *Bridging the domain gap: A transferable dynamic routing enhancer for robust aerial detection under adverse weather*

- 作者：Yu Wan et al.
- 期刊：ISPRS Journal of Photogrammetry and Remote Sensing, 2026, Vol. 242, pp. 1–18
- DOI：https://doi.org/10.1016/j.isprsjprs.2026.08.041
- 代码：https://github.com/KIKYOUWY/TDRE
- 数据集：CAD-ADD（Cross-Application Degradation Aerial Detection Dataset）

**为什么保留 TDRE，但不再把它作为核心任务基线？**

TDRE 的重点是多种恶劣天气退化下的可迁移航拍图像增强，包含清晰图像旁路、动态专家路由、多空间恢复损失和检测导向增强等设计。它覆盖雾、沙尘、低照度等退化，并在农业病害、城市垃圾、野外救援和智能交通等应用域开展评估。

这些工作对本研究仍然重要：TDRE 可作为多天气增强和跨应用迁移的代表性对照，用来检验通用增强路线在雾天无人机小目标检测及未见场景测试中的表现。但它的研究重点比本研究的最终任务更宽泛，因此不如 CCFA-Net 直接对应“雾天无人机检测协同”这一核心任务。

**TDRE 的已知设计及其对本研究的启示：**

| TDRE 设计 | 论文中的作用 | 本研究需要避免的重复 |
|---|---|---|
| Clear-Sky Perceptron | 识别清晰输入并旁路增强 | 不把清晰图像旁路作为主要创新 |
| DR-MoE | 通过动态专家处理不同退化 | 不把多天气专家路由作为主要创新 |
| Multi-Space Restoration Loss | 在 RGB、HSV、LAB 等空间约束恢复 | 不把多颜色空间损失简单改名作为创新 |
| Detection-oriented Enhancement Loss | 利用目标区域信息引导增强 | 不把检测标注掩码引导增强作为主要创新 |
| 轻量增强模块 | 尽量减少对下游检测器的改动 | 可作为效率和部署方面的对比参考 |

TDRE 论文报告的 CAD-ADD 结果、参数量和推理时间，应按论文原始实验设置引用。不能据此直接推断其已完成严格的“未见地点、未见飞行高度、未见雾条件”域泛化验证。真实飞行可视化也不能替代有标注未见场景测试集上的系统定量评估。

### B.3 基线体系与分工

| 方法 | 在本研究中的定位 | 主要回答的问题 |
|---|---|---|
| **CCFA-Net** | **核心任务基线，优先复现** | 专门的雾天无人机协同检测方法能达到什么水平？ |
| **TDRE** | 重要辅助对比基线 | 多天气动态增强与跨应用迁移路线在本任务中表现如何？ |
| HazyDet / DeCoDet | 数据基准与基础检测基线 | 不增加新增强或泛化模块时，检测器的基础能力如何？ |
| DehazeFormer + DeCoDet | 独立去雾串联基线 | 先去雾再检测是否优于直接检测？ |
| UDN | 恢复不确定性建模参考 | 如何估计图像恢复的不确定性？ |
| CSDA | 类别—尺度条件学习参考 | 如何构造类别与尺度条件的特征约束？ |
| UAV Frequency Domain Disentanglement | UAV 域泛化参考 | 如何在源域训练中学习更稳定的域泛化表示？ |

**关键术语边界：** CCFA-Net 名称中的 “Cross-domain” 不能仅凭名称就等同于严格 Domain Generalization。需要核查其训练、验证和测试协议，确认目标场景是否完全未参与训练、模型选择和超参数调整。TDRE 的跨应用/跨测试集评估也需要逐项核对，不能自动视为严格未见场景泛化。

## C. CCFA-Net 已覆盖什么？本研究还要验证什么？

以下是研究切入点，不应在未完成全文、代码和实验协议核查前，把它们写成 CCFA-Net 已被证实的缺陷。

| CCFA-Net 已涉及的方向 | 本研究进一步提出的问题 | 需要完成的验证 |
|---|---|---|
| 去雾与检测协同优化 | 恢复特征是否真实、稳定，并对检测有帮助？ | 恢复扰动、特征一致性及恢复误差分析 |
| 原始雾图与恢复特征融合 | 融合机制能否识别不可靠恢复信息？ | 与固定融合、普通注意力和原方法比较 |
| 多尺度前景建模 | 同类不同尺度目标在不同场景中是否保持稳定？ | 类别—尺度分组的跨场景特征与检测分析 |
| 雾天无人机数据集评估 | 是否能泛化到训练中完全未见的场景？ | 按地点/飞行序列/雾条件隔离的严格 DG 测试 |

**需要检验的核心假设：**

- H1：去雾质量改善并不必然带来小目标检测性能提升。
- H2：恢复特征的不稳定性与小目标误检、漏检或定位误差存在可重复关联。
- H3：可靠性引导融合优于不考虑可靠性的普通融合。
- H4：可靠性约束的类别—尺度条件源域泛化能改善严格未见场景的 AP_small。

如果 H1 或 H2 不成立，必须调整或放弃相应的可靠性建模假设，不能为了保留预设模块而强行解释实验结果。

## D. 新方法的拟解决路径

### 问题一：恢复特征是否可靠？

**拟方法：检测任务驱动的恢复可靠性估计。**

- 对同一雾天输入施加合理的恢复扰动，例如输入扰动、恢复强度变化或不同恢复分支。
- 提取不同恢复结果中的目标区域特征，计算特征一致性、预测分歧或定位波动。
- 将这些量转化为局部、实例级或尺度相关的可靠性分数。
- 在有配对清晰参考的合成雾数据上，验证可靠性与恢复误差的关系；再分析可靠性与分类错误、漏检和定位误差的关系。

注意：多次恢复结果一致不等于恢复结果正确。必须用恢复误差和下游检测错误验证可靠性分数是否有意义。

### 问题二：如何使用可靠的恢复特征？

**拟方法：可靠性引导的原始雾图—恢复特征选择性融合。**

- 建立原始雾图特征分支和恢复图像/恢复特征分支。
- 根据局部或实例级可靠性估计融合权重。
- 恢复特征可靠时提高其权重；恢复不可靠时保留更多原始观测特征。
- 与固定相加、拼接、普通注意力、CCFA-Net 原有融合方式进行对照。
- 重点报告 AP_small、Recall、定位误差，以及浓雾和极小目标子集结果。

只有当可靠性引导融合稳定优于普通融合，且收益能通过消融实验归因于可靠性信息时，这个模块才具有充分的实验依据。

### 问题三：如何泛化到未见场景？

**拟方法：恢复可靠性约束的类别—尺度条件源域泛化。**

- 按目标类别和目标像素面积建立类别—尺度分组。
- 仅利用训练源域，统计同类同尺度目标在不同源场景中的特征变化。
- 探索类别—尺度条件的 CORAL、MMD 或对比学习约束。
- 用恢复可靠性调节约束强度，避免把不可靠恢复特征强行对齐。
- 设置类别均衡、权重下限和困难小目标保留机制，避免模型忽略最难样本。

目标域不得参与训练、伪标签生成、模型选择或超参数调整。若使用了目标域无标注数据进行适配，应明确称为 Domain Adaptation，而不是严格 Domain Generalization。


## 面向雾天无人机小目标检测的可靠性引导跨场景域泛化研究

## 1. 研究定位与目标

**目标期刊：** IEEE Transactions on Vehicular Technology (TVT)

**研究方向：** - 无人机航拍小目标检测（UAV Small Object Detection） -
雾天图像复原与感知友好去雾（Image Dehazing） - 跨场景域泛化（Cross-Scene
Domain Generalization） - 恢复信息可靠性建模（Restoration Reliability
Estimation）

### 1.1 现实问题

现实无人机飞行中，飞行高度增加会使车辆、行人等目标在图像中的像素尺寸减小；雾气会进一步削弱目标边缘、纹理和局部结构。去雾网络虽然能够改善视觉质量，但在浓雾和远距离小目标场景中，也可能生成不可靠的纹理和细节，导致检测器误检或漏检。

此外，不同地点、飞行高度和雾浓度会造成场景分布变化，使模型在训练场景中表现良好，却难以适应未见场景。

### 1.2 核心科学问题

现实雾天中，图像恢复的不确定性如何影响不同类别、不同尺度小目标的判别特征？如何利用恢复信息的可靠性，指导模型学习在未见地点、未见飞行高度和未见雾条件下仍然稳定的小目标表示？

### 1.3 总体研究假设

视觉复原质量与小目标检测有效性并不总是一致。对于浓雾、远距离和极小目标，恢复网络可能生成不稳定细节；如果检测器过度依赖这些恢复特征，可能造成误检和漏检。通过估计恢复信息的可靠性，并将其引入类别---尺度条件的跨场景特征学习，有望提升未见场景下的小目标检测鲁棒性。

> 以上是待实验验证的研究假设，不能在实验前当作已证实结论。

## 2. 拟研究的三个方向

### 方向一：检测任务驱动的恢复信息可信度建模

**研究问题：**
去雾结果在视觉上更清晰，不代表它一定更有利于小目标检测。如何判断恢复信息是否稳定、是否包含可靠的目标判别信息？

拟开展工作：

1.  分析不同雾浓度、目标尺度下去雾前后的检测性能变化。
2.  比较原始雾图特征与去雾图特征对分类和定位的贡献。
3.  对同一输入施加不同恢复扰动，比较恢复特征的一致性。
4.  建立恢复信息可靠性估计方法。
5.  使用可靠性信息控制原始特征与恢复特征的融合。

初步思路：对同一雾图生成多个扰动恢复结果，比较同一区域的恢复特征稳定程度。若特征变化较大，则降低该区域恢复特征对检测器的影响。

**注意：**
恢复一致性不等于真实恢复正确性。需要结合合成雾配对数据、清晰参考图像、检测结果及可靠性校准实验进行验证。

### 方向二：恢复可靠性约束的类别---尺度条件跨场景泛化

**研究问题：**
不同场景下，同一类别小目标的特征可能发生变化；不同目标尺度下，纹理、边缘和语义信息的稳定程度也不同。普通全局分布对齐可能忽略类别与尺度差异，甚至把背景和不可靠恢复特征一起对齐。

拟开展工作：

1.  提取不同类别目标的判别特征。
2.  按目标像素面积划分尺度区间。
3.  分析不同源场景下类别---尺度特征分布的变化。
4.  研究恢复可靠性对特征对齐的约束作用。
5.  设计类别---尺度条件的跨场景特征泛化方法。

初步思路：将类别条件、尺度条件和恢复可靠性引入联合特征学习，使可靠的目标判别信息在不同源场景之间保持稳定，同时避免不可靠恢复信息主导分布对齐。

**创新性提醒：**
类别---尺度联合特征学习已有相关工作，不能宣称首次提出类别---尺度联合建模。重点应放在从域适应转向严格域泛化，以及恢复可靠性约束带来的新作用。

### 方向三：未见场景下的鲁棒检测验证

该方向主要是实验协议，而不是独立网络模块。需要分别验证：

-   **未见飞行高度：**
    训练使用低空、中空场景，测试使用未参与训练的高空场景。
-   **未见地点：** 训练使用若干地点，测试使用完全留出的地点。
-   **未见雾条件：**
    训练使用有限雾浓度范围，测试使用未见雾浓度或真实雾场景。

严格域泛化要求目标测试场景不参与训练、伪标签生成、模型选择和超参数调整。若目标域数据参与训练，应准确称为域适应，而不是严格域泛化。

### 5.2 数据划分原则

-   源域：训练期间允许使用的地点、飞行高度和雾条件。
-   目标域：完全留出的地点、高度或雾条件。
-   目标测试域不能参与训练、伪标签生成和模型选择。
-   尽量按原始视频、拍摄序列或地点划分，避免相邻帧泄漏。
-   统一不同数据集的类别映射和目标尺寸定义。

如果数据集没有可靠的飞行高度元数据，不能直接声称完成了未见高度泛化；可以先按目标像素面积分组，或寻找带有可靠高度信息的数据。若没有地点元数据，应称为跨数据集泛化，而不是未见地点泛化。

## 6. 第一轮实验：证明研究问题真实存在

第一轮不设计新网络。以 CCFA-Net 为主要参照，先完成以下诊断实验。

### 实验 1：去雾是否真正改善小目标检测？

比较： 1. 原始雾图 + 检测器； 2. DehazeFormer + 检测器； 3. CCFA-Net。

统计： - AP_small； - AP50； - Recall； - mAP。

目标：分析去雾是否改善图像质量，却未改善小目标检测。

### 实验 2：不同目标尺度下，去雾特征是否可靠？

按照目标像素面积划分小、中、大目标，比较： - 原始图像特征； -
去雾图像特征； - 两者融合后的检测特征。

目标：观察不同尺度下的特征贡献和检测性能变化。

### 实验 3：不同雾浓度下，恢复特征是否稳定？

使用合成雾数据或具有雾浓度信息的数据，比较不同雾强度下的恢复结果。设计不同恢复扰动，提取多组恢复特征，分析特征方差、一致性和检测错误之间的关系。

### 实验 4：恢复特征不稳定是否与误检、漏检相关？

重点观察： - 目标区域； - 目标周围背景； - 远距离小目标； - 浓雾区域。

通过可视化和统计分析判断恢复特征不稳定是否与检测错误相关。

**判断原则：**
如果现象没有得到实验支持，应调整研究假设，而不是强行加入不确定性模块。

## 7. 第二轮：新方法设计

只有第一轮实验支持研究假设后，再开展新方法设计。

### 模块一：恢复可靠性估计

-   对输入图像进行不同恢复扰动；
-   提取多组恢复特征；
-   估计局部特征稳定性；
-   结合清晰参考或合成雾数据验证可靠性。

### 模块二：可靠性引导的特征融合

融合原始雾图特征和去雾特征： - 恢复可靠时，充分利用恢复特征； -
恢复不可靠时，更多保留原始观测信息。

### 模块三：恢复可靠性约束的类别---尺度泛化

-   按类别和尺度构建条件特征；
-   利用可靠性控制跨源域分布对齐；
-   避免全局 MMD 式对齐忽略类别和尺度；
-   防止困难样本被过度抑制；
-   不使用未见目标域统计信息。
