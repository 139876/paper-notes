# Cross-Modal Object Detection via UAV — 速查笔记

> 论文: Li Ang et al., "Cross-Modal Object Detection via UAV", IEEE Trans. Vehicular Technology, Vol.72, No.8, Aug. 2023.
> DOI: 10.1109/TVT.2023.3262129

## 一句话
训练期用"红外老师"教"彩色学生"，部署期只带学生 —— 扔掉红外相机、融合模块和老师模型。

## 核心范式（CKD）
```
训练: X_IR -> IR检测器(老师,冻结) --知识--> RGB检测器(学生,可训练) <- X_RGB
      搬运通道: SFI(特征层) + API(预测层)
部署: X_RGB -> RGB检测器(学生) -> 框+类别     [IR检测器/SFI/API 全部删除]
```

## 两个核心模块

### SFI — Selective Feature Imitation (选择性特征模仿)
1. 维度对齐: T_IR/T_RGB = 3x3 Conv + BN + ReLU（可学习，非 ReLU 等无参数激活）
2. 相似度图: M = (F_IR · F_RGB) / (||F_IR|| ||F_RGB||)   [reshape 成 HW×C 后逐位置余弦相似度]
3. 反相似度图: M̄ = 1 - M
4. 分解: F^com = M·F, F^res = M̄·F
5. 损失: L_f = π1||F_IR^com - F_RGB^com||_2 + π2||F_IR^res - F_RGB^res||_2,  π2 > π1
   实际取值: π1=0.3, π2=0.7

### API — Adaptive Prediction Imitation (自适应预测模仿)
1. 蒸馏强度: w_ciou = |D_RGB ∩ D_IR| / |D_RGB ∪ D_IR|  (跨模态 IoU, ∈[0,1])
2. 分类: L_KL = w_ciou · KL(p_IR || p_RGB) ; L_CE = CE(p_RGB, y)
          L_cls = ρ·L_KL + (1-ρ)·L_CE,  ρ=0.7
3. 定位: L_loc^ts = w_ciou ||R_IR - R_RGB||_2^2  (老师拉)
          L_loc^L  = smoothL1(R_RGB, R)          (真值拉)
          L_loc = λ·L_loc^ts + (1-λ)·L_loc^L,  λ=0.5
4. 总损失: L = L_f + L_cls + L_loc
5. 优化: IR检测器参数冻结, RGB检测器端到端更新 (Algorithm 1)

## 实验设置
- 数据集: DroneVehicle — 28,439 对 IR-RGB, 5类(car/truck/bus/van/freight car)
  17,990 训练 / 10,449 测试; 角度 15°/30°/45°/90°, 高度 80/100/120m, 白天/夜晚/暗夜
- 目标框数: 训练 RGB 286,793 / IR 316,411; 测试 RGB 165,777 / IR 184,106
- 主干: ResNet50 + FPN; 输入 resize 840×712, 水平翻转 p=0.5
- 优化: SGD, 50 epoch, lr 0.001 (每 20 epoch ×0.1), wd 0.0005, momentum 0.9, batch 8
- 硬件: 2× Xeon E5-2695 v4 + 8× Tesla P100（注意: 未在 Jetson TX2 上实测）
- 指标: mAP, IoU>0.5 判为 TP

## 消融
| 配置 | mAP |
|---|---|
| Oriented-RCNN | 56.1 |
| + SFI | 59.2 (+3.1) |
| + API | 57.5 (+1.4) |
| + SFI + API | **60.7** |

- 特征蒸馏贡献 > 预测蒸馏贡献; 两模块不冲突
- π1 扫描 (π1+π2=1): π1=0.3 最优 (59.21); π1=0 → 58.54, π1=1 → 58.29 → 印证"残差 > 共性"
- w_ciou 消融: 全用 57.5 / 只分类用 57.2 / 只定位用 57.3 / 全不用 56.9 → w_ciou 有效但增益有限

## 术语速查
- **模态 (modality)**: 不同的信息形式。RGB=可见光, IR=红外/热成像
- **旋转框 (oriented box)**: 四边形, 贴合长条形目标; 水平框会包含大量背景
- **mAP**: 平均精度均值, 综合衡量"找得准 + 分得对"
- **IoU**: 交并比 = 重叠面积/并集面积
- **知识蒸馏 (KD)**: 大/强模型(老师)把"经验"传给小/弱模型(学生)
- **本文特殊性**: 老师学生结构完全相同, 知识来自"模态不同"而非"模型更大"
- **共性 vs 残差**: 两模态都看见的部分 vs 只有某模态看见的部分

## 局限 / 值得质疑的点
1. 训练成本翻倍(两个检测器都要前向), 论文未在 Jetson TX2 上实测 FPS/延迟/功耗 — 核心主张"能部署"缺硬件验证
2. "模型压缩"含义被弱化: 老师学生同构, 真正省的是红外相机 + 融合开销, 不是参数减半
3. 未与真正的同模态 KD 基线(FitNet / Attention Transfer)对比, 无法量化 SFI 相对普通特征蒸馏的净增益
4. 只在 DroneVehicle 一个数据集、5 个类别上验证, 超参稳健性未知
5. 相似度图 M 的逐像素全通道余弦相似度计算开销未报告, 对特征尺寸/通道敏感
6. 定性实验仅 4 张样例, 夜晚场景证据较弱; mAP 60.7 仍低于真正多模态的 63.2
