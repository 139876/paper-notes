# 第 2 讲：基线模型与旋转框检测

> [!tip] 本讲目标
> 搞懂两个问题：**为什么航拍检测要用旋转框**，以及 **Oriented R-CNN 的三段式**。
> 本文**不改动 Oriented R-CNN 的任何结构**——所有创新都发生在"如何把老师的知识搬给学生"。所以基线是什么，直接决定了后面 SFI/API 的接口。

---

## 2.1 为什么需要"旋转框"？

![[rotated_boxes.png]]

航拍图里的车辆：**细长、且角度各异**（俯视时车头朝向随机）。

| | 水平框（Horizontal BBox） | 旋转框（Oriented BBox） |
|---|---|---|
| 形状 | 正立的矩形 | 任意角度的四边形 |
| 对细长目标 | 会把**大片背景**一起框进去 | **紧贴**目标轮廓 |
| 区域特征 | 被背景污染 | 干净 |
| IoU | 低（重叠率差） | 高 |
| 分类置信度 | 随之下降 | 保持 |

> 🎯 **类比**
> 给一张**躺着的长凳**拍照。用水平框 = 你硬要套一个正方形框把它装进去，框里一大半是地板；旋转框 = 你顺着凳子的角度画个斜框，框里就只有凳子。
> **背景污染**就像：你在嘈杂的食堂里拍一张只有半张脸的照片，再强的识别模型也认不准。

> ⚠️ **长宽比越大的目标，水平框受损越重**——这正是航拍车辆检测的痛点。

## 2.2 Oriented R-CNN 的三段式

> **出处**：Xie et al., *Oriented R-CNN for Object Detection*, ICCV 2021（本文引用为 [22]）

```
Backbone (ResNet50 + FPN)  →  ORPN  →  ORCN
      多尺度特征图           带角度的     精修边界
                              旋转候选框    + 判定类别
```

### ① Backbone：ResNet50 + FPN

- **ResNet50**：主干网络，提取语义特征
- **FPN（Feature Pyramid Network）**：生成**多尺度**特征金字塔
  - 无人机在 80 m 高空拍的车很小，在 30 m 高空拍的车很大 → 单一尺度特征图抓不住
  - FPN 同时输出"高分辨率小目标特征"和"低分辨率大目标特征"，让网络同时处理尺度剧变

> 🎯 **类比**：FPN 像"用不同放大倍率的镜头各拍一张"。远景镜头看全貌，近景镜头看细节，检测器可以自己挑用哪张。

### ② ORPN（Oriented RPN）：生成带角度的旋转候选框

这是与普通 RPN 的唯一区别——输出的候选框带**旋转角度**。

**中点偏移表示（近乎零成本）**：锚框回归出 6 个量

$$
(\delta_x, \delta_y, \delta_w, \delta_h, \delta\alpha, \delta\beta)
$$

- `deltaα / deltaβ`：**相对外接框上边与右边的中点**定位角度
- **好处**：**无需枚举旋转锚框**。普通 RPN 只回归 4 个量，本文风格的多角度枚举会带来指数级的锚框数量

> 🎯 **类比**：不是"把卷尺转 15° 一格一格量"，而是"**先量出中心在哪，再说我往哪边歪了多少**"——两个数就够了。

### ③ ORCN（Oriented RCNN Network）：精修边界 + 判定类别

在候选框基础上做两件事，正是检测的两段：
- **分类**：这个框是轿车 / 卡车 / 公交 / 厢式车 / 货车
- **回归**：把四条边精修到更准

> 📌 本文关心的两个输出正好对应：
> - **分类** → API 要搬的"分类知识"
> - **回归** → API 要搬的"定位知识"
> - **Backbone 输出的特征图** → SFI 要搬的"特征知识"

## 2.3 本文为什么不换基线？

| | 为什么不换 |
|---|---|
| 不用更快的检测器 | 因为**老师和学生必须同构**，否则参数量、速度的数字就不可比了 |
| 不用端到端旋转框检测器（如 FCOS、PSC） | Oriented R-CNN 是 **two-stage**，有**显式的 RPN 输出和分类/回归头**，方便在特征层和预测层分别做蒸馏 |

> [!important] 一句话记住
> **IR 与 RGB 各自就是一个完整的 Oriented R-CNN；所有创新都发生在"如何把老师的知识搬给学生"。**

> 🎯 **类比**
> 选 Oriented R-CNN 就像选"标准配置的教练和学生"——两人用的是**同一套教材**（同结构），
> 那么最后成绩的差距就**只能**来自"老师看到了学生看不到的东西"。这让实验结论非常干净。

## 2.4 论文 Eq.(1)：中点偏移的完整形式

$$\Delta\alpha = \delta_\alpha w, \quad \Delta\beta = \delta_\beta h$$
$$w = a_w e^{\delta_w}, \quad h = a_h e^{\delta_h}$$
$$x = \delta_x a_w + a_x, \quad y = \delta_y a_h + a_y$$

其中 $(a_x, a_y, a_w, a_h)$ 是锚框的中心与宽高，$(\delta_x, \delta_y, \delta_w, \delta_h, \delta\alpha, \delta\beta)$ 是回归出的偏移量。

- 宽高用**乘性**（$e^{\delta}$）编码 → 保证恒为正
- 角度用**加性**编码

> [!note] 你不需要现在推导它
> 这条公式只是为了让论文 Eq.(1) 能读通。**真正需要你记住的只有一句**：
> **回归输出 6 个量，其中 2 个管角度，且角度以"外接框上边/右边的中点"为参照。**
