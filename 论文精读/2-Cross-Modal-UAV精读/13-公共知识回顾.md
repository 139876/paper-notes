## 一、🧬 模型压缩与跨模态（本篇的核心地基，06-模型压缩与跨模态）

### 模型压缩全景
| 路线 | 做什么 | 代价 |
|---|---|---|
| **剪枝** | 删掉不重要的权重/通道 | 需要找"不重要"的判据 |
| **量化** | 权重从 FP32 压到 INT8 | 精度掉一点，速度翻倍 |
| **知识蒸馏** | 大老师教小学生 | **要重新训练学生** |
| **NAS** | 搜最优架构 | 搜索成本极高 |

> 🎯 **本篇落在「知识蒸馏」**：因为它**不改变部署时的网络结构**，
> 推理开销和原来一样 —— 无人机机载算力吃紧，这是**最划算的路线**。

### 知识蒸馏四件套
| 概念 | 一句话 |
|---|---|
| **Teacher / Student** | 大而准 / 小而快 |
| **软标签（logits + 温度 T）** | `p = softmax(z/T)`；**T 越大，分布越"软"**，能传递"类别之间的关系"而不只是"谁是第一名" |
| **蒸馏损失** | `L = α·L_hard + (1-α)·L_soft`，硬标签管"对不对"，软标签管"像不像" |
| **特征蒸馏** | 直接对齐中间**特征图**（本篇的 **SFI** 干的就是这个） |

> 📌 **为什么用软标签**：一个 teacher 说"这张图 60% 是车、30% 是卡车"，
> 比只说"这是车"信息量大得多 —— **暗知识（dark knowledge）**。

### 跨模态技术全景
| 模态组合 | 典型场景 | 难点 |
|---|---|---|
| **RGB + IR** | 夜间、烟雾 | 模态**不对齐**、语义**互补** |
| **RGB + Depth** | 3D 场景 | 深度稀疏、噪声 |
| **RGB + 可见光/高光谱** | 遥感 | 通道数差异巨大 |
| **单模态 → 单模态** | 本文 | **模态鸿沟**：两种模态的特征分布差很远 |

> 🔑 **核心矛盾**：跨模态的收益来自"**互补**"，代价是"**鸿沟**"。
> 本文的 **SFI（选择性特征模仿）** 就是**只模仿"该模仿的那部分特征"**，
> 而不是无脑对齐全部 —— 这正是蒸馏思想在跨模态上的应用。

## 二、检测任务与评测（04-检测任务与评测）

| 结论 | 复述 |
|---|---|
| bbox | 4 个数框住目标；COCO 存 **`[x, y, w, h]`** |
| mAP | IoU 匹配 → TP/FP/FN → 按置信度排序 → **P-R 曲线下面积 = AP** → 类别平均 |
| **旋转框** | UAV 俯视目标**朝向任意**，水平框会框进大量背景 → 用 **旋转框（HBB → OBB）** |
| 两阶段 vs 单阶段 | 本篇 baseline 是**水平框检测器**（Faster R-CNN 等） |
| 置信度 ≠ 质量 | 分类分高不代表框得准 |

> 🎯 **本篇用在哪**：跨模态的增益最终要落到 **mAP** 上 ——
> **API（自适应预测模仿）** 就是在模仿 **teacher 的预测分布**，直接优化"排序后的质量"。

## 四、🔥 本篇最容易忘的 4 条（考前默背）

1. **软标签 + 温度 T**：T 越大分布越软，能传递"类别间关系"（暗知识）。
2. **蒸馏损失 = α·硬标签 + (1−α)·软标签**，两个都要，比例是旋钮。
3. **特征蒸馏 ≠ 分类蒸馏**：前者对齐**中间特征图**（SFI），后者对齐**输出分布**（API）。
4. **跨模态的矛盾是"互补 vs 鸿沟"** —— 所以方法都强调**选择性**（只学有用的），而不是全盘对齐。

## 五、🧪 自测（先合上答案写）

<details>
<summary>Q1：知识蒸馏里"软标签"到底软在哪？温度 T 起什么作用？</summary>

硬标签是 one-hot（只有 0/1）；软标签是 `softmax(z/T)` 的**完整概率分布**。
`T` 越大分布越平（越"软"），能传递类别之间的相似性（暗知识）；`T=1` 就是普通 softmax。
</details>

<details>
<summary>Q2：SFI 和 API 分别在模仿什么？</summary>

**SFI = Selective Feature Imitation** → 模仿 teacher 的**中间特征图**（选择性：只模仿该模仿的部分）。
**API = Adaptive Prediction Imitation** → 模仿 teacher 的**输出预测分布**。
一个是"特征层"，一个是"决策层"。
</details>

<details>
<summary>Q3：为什么 UAV 检测要用旋转框？</summary>

俯视视角下车辆/飞机**朝向任意**，水平框会裹进大量背景（尤其细长的车），
IoU 被稀释 → 用 **OBB（旋转框）** 贴合真实朝向。
</details>

<details>
<summary>Q4：跨模态方法为什么都强调"选择性"？</summary>

因为跨模态**既有互补也有鸿沟**：有些特征天生不可迁移（RGB 的纹理 vs IR 的热对比），
无脑对齐会引入负迁移；**只迁移"能迁移且有用"的部分**才有效。
</details>
