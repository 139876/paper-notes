# 🗺️ 图论综合应用报告 · 索引 MOC

> [!abstract] 报告一句话
> 把**重庆大学虎溪校区**的真实路网抽象成 **23 顶点 / 26 边的加权无向图**，
> 用 **Dijkstra** 算出 7 个配送点之间的最短步行距离，
> 再用**最近邻 + 2-opt** 求闭合巡回，并用 **Held–Karp** 作精确对照。
>
> 📌 **题目**：基于图论的重庆大学虎溪校区快递配送路径优化研究

### 📄 导出 PDF（课程要求「附件用 PDF」）

`附件/图论综合应用报告.html` 是**完全自包含**的单文件（图片 base64 内联 +
MathJax 内联 + A4 打印样式），双击用浏览器打开即可。

| 方式 | 操作 |
|---|---|
| **一键（推荐）** | 双击 `附件/导出PDF.command` → 调用本机 Chrome 无头打印，自动生成 `附件/工程/report/图论综合应用报告.pdf` |
| 手动 | Chrome/Edge 打开 HTML → `Cmd+P` → 「另存为 PDF」→ 纸张 A4 → 勾选「背景图形」 |

> 每个 `#` 一级标题自动另起一页；表格不跨页断开；公式由 MathJax 渲染为矢量 SVG，缩放不糊。
