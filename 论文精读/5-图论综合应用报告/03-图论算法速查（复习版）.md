## 二、Dijkstra（人话版）

> **"先走到目前确认最近的路口，再问那里最近的下一个路口。"**

| 要素 | 记法 |
|---|---|
| 核心动作 | 取 `d` 最小的未确定顶点 `u` → 加入 S → 对邻居松弛 |
| 松弛 | `d[v] = min(d[v], d[u] + w(u,v))` |
| 正确性支点 | **边权非负** ⇒ 当前最近的顶点不可能再变得更近 |
| 复杂度 | `O((V+E) log V)`（堆实现） |
| 前提 | **所有边权非负**；有负权得用 Bellman-Ford |

**本报告怎么验证它**：与 NetworkX 的 `single_source_dijkstra_path_length`
逐点对比，最大偏差 **0**。

## 三、TSP 的数学模型（要能默写）

$$\min \sum_i \sum_j d_{ij} x_{ij}$$

三条约束：
1. **出度 = 1**：$\sum_j x_{ij} = 1$
2. **入度 = 1**：$\sum_i x_{ij} = 1$
3. **流量守恒**：$\sum_i x_{ij} - \sum_i x_{ji} = 0$
4. **子回路消除**（MTZ 割变量）

> **本报告的关键**：$d_{ij}$ 是**沿校园道路的最短距离**，不是直线距离。
> 这是"图论建模"与"数学题"的分界线。

## 四、最近邻 / 2-opt / Held–Karp 三兄弟

| | 最近邻 NN | **2-opt** | Held–Karp |
|---|---|---|---|
| 一句话 | 每次去最近的 | 剪两条边、反向重接，变短就留 | 状态压缩 DP，穷尽所有子集 |
| 复杂度 | $O(n^2)$ | $O(k n^2)$ | $O(2^n n^2)$ |
| 保证最优 | ❌ | ❌（局部最优） | ✅ |
| 规模上限 | 无 | 无 | n≤15~16 |
| 本报告实测 | 平均 Gap 7.80% | **平均 Gap 0.00%**，20/20 达最优 | 作标准答案 |

### 2-opt 的改进条件（要能看懂）
$$\Delta = \big(d_{ij} + d_{i+1,j+1}\big) - \big(d_{i,i+1} + d_{j,j+1}\big) < 0 \Rightarrow \text{改进}$$

### 工程技巧：多次随机重启
2-opt 对初始解敏感 → 随机生成 N 个初始解各跑一次，取最优。成本≈0，收益明显。

## 七、容易被问的三个问题

**Q：为什么不用直线距离算配送距离？**
A：配送员只能走路。直线距离会低估弯路成本，算出的路线物理上不可执行。

**Q：为什么用 2-opt 而不是直接 Held–Karp？**
A：规模大了精确解不可行（见规模感表）。而且 2-opt 实测平均 Gap 为 0%，性价比远高于指数级精确解。

**Q：你的数据可靠吗？**
A：**坦白说**：节点集合与边连接关系来自候选表并已核验拓扑结构；
但坐标与边长尚未实地量测，所以**绝对里程数值待核**，
**算法实现正确性与相对比较结论是可靠的**。核验流程见
[[paper-notes/论文精读/5-图论综合应用报告/05-数据核验清单|数据核验清单]]。
