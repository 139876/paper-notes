# 方向 5 · 注意力机制谱系

> [!info] 这是**方向知识脉络**

> 📌 底部三个链接区：**先补公共基础**（地基层）→ **本文用在哪**（论文层）→ **同方向其他笔记**（横向串联）。

## 5.1 一句话定位

> **注意力 = 让网络自己决定"该看哪里、该重用什么"，而不是对所有位置一视同仁。**

它已经从"Transformer 的招牌"变成了**卷积网络的通用增强件**。

---

## 5.2 演进主线：三个轴

```
① 压在哪？      通道注意力 → 空间注意力 → 通道+空间
② 怎么算权重？  硬编码/统计 → MLP → 卷积 → Transformer
③ 要不要位置？  纯通道（丢位置）→ 纯空间（丢通道）→ 两者都要且保留位置
```

---

## 5.3 关键节点（按时间）

| 年份 | 方法 | 压在哪 | 关键创新 |
|---|---|---|---|
| 2017 | **SENet (SE Block)** | **通道** | " squeeze-and-excitation"：全局池化得到通道描述 → MLP → 通道权重 |
| 2018 | **CBAM** | **通道 + 空间** | **串联**两个注意力：先通道后空间 |
| 2020 | **ECA (Efficient Channel Attention)** | 通道 | 用 **1×1 卷积**替代 MLP，降开销 |
| 2021 | **Coordinate Attention (CA)** | 通道 + 空间 | **把位置信息注入通道注意力**（Hou et al., CVPR 2021） |
| 2019 | **Strip Pooling (SP)** | 空间 | 用 **1×(h 或 w) 的条带池化**分别编码水平/垂直方向信息（Ho et al., ICCV 2019） |
| 2022+ | **Large Kernel Conv (LKV)** | 空间 | 用大核卷积（如 21×21）近似全局注意力 |
| 2021+ | **Vision Transformer / Swin** | 全局 | 自注意力，但**不显式拆成通道+空间** |

## 5.4 三个必须理解的细节

### ① SE Block：通道注意力的原型

```
输入 (C, H, W)
  │
  ├─ Global Average Pooling → (C, 1, 1)      ← squeeze：把空间维压掉
  ├─ FC → ReLU → FC → Sigmoid → (C, 1, 1)    ← excitation：学通道权重
  └─ 逐通道相乘 → (C, H, W)
```

> **Squeeze 丢掉了位置信息**（每个通道只有一个标量）。
> 这是 SE 的优点（轻量）也是它的天花板。

### ② Coordinate Attention（CA，Hou et al. CVPR 2021）—— **MFAM 的直接血缘之一**

**问题**：SE 的通道注意力没有位置信息 —— "哪个通道重要"和"**在哪里**重要"分不开。

**解法**：把坐标信息编码进通道注意力。

```
输入 (C, H, W)
  │
  ├─ 沿 H 方向池化 → (C, H, 1)   ← 水平方向的位置信息被保留
  ├─ 沿 W 方向池化 → (C, 1, W)   ← 垂直方向的位置信息被保留
  ├─ Concat → (C, H+W, 1)
  ├─ 1×1 Conv + BN + ReLU → (C/r, H+W, 1)
  ├─ Split 回两半 → (C/r, H, 1) 和 (C/r, 1, W)
  ├─ 各自 1×1 Conv → (C, H, 1) 和 (C, 1, W)
  └─ Concat → (C, H, W)  ← 通道权重里带了位置 ✅
```

> 🎯 **比喻**
> SE 像"**按科目给全班加权重**"（不知道哪个学生在哪）。
> CA 像"**按科目 × 按座位**"给权重 —— 科目（通道）和座位（位置）都在里面。

> [!important] 本文的 MFAM 用的就是 CA 的骨架
> 我核对过：**论文全文没有引用 Hou et al. 2021**（Coordinate Attention），
> 但 MFAM 的"δ 依赖范围"实验（实测 407/576 个位置参与依赖）呈现出的**十字形依赖结构**，
> 与 CA 的 **H 方向池化 + W 方向池化**高度一致 —— **这是一处未标注引用**。
> 见 [[08-第7讲-MFAM多尺度前景感知]]。

### ③ Strip Pooling（SP，Ho et al. ICCV 2019）—— **MFAM 的另一个血缘**

**问题**：大核池化（把整张图压成 1×1）会**丢方向信息**；标准 3×3 池化感受野太小。

**解法**：用**条带**代替方块。

| 方向 | 池化核 | 输出 | 保留的信息 |
|---|---|---|---|
| 水平 | 1 × (h-1) | (C, 1, W) | **水平**方向的上下文 |
| 垂直 | (w-1) × 1 | (C, H, 1) | **垂直**方向的上下文 |

两条路分别编码，再**拼接 + 1×1 卷积**融合。

> 🎯 **比喻**
> 把一张街景**横向扫一条**（得到"每列的亮度分布"）和**纵向扫一条**（得到"每行的亮度分布"）。
> 前者擅长找**竖直的杆子**（路灯、杆子），后者擅长找**水平的长条**（道路边界、屋檐）。
>
> **而"找杆子"正是 UAV 场景需要的** —— 车辆是长条形的，雾里的远车只剩一条淡影。

> [!important] 本文的 MFAM 用的就是 SP 的骨架
> 同理，**论文全文没有引用 Ho et al. 2019**（Strip Pooling）。
> MFAM 里 `11×1` 和 `1×11` 的条带卷积（占 MFAM 参数的 **86.9%**）就是条带池化的直接体现。
> **又是一处未标注引用。**

## 5.5 注意力机制和"残差/卷积"的关系

| 机制 | 加在哪 | 解决什么 |
|---|---|---|
| **残差连接** | 块与块之间 | **梯度通路**、让深网络训得动 |
| **注意力** | 块内部或特征之后 | **空间/通道的加权**，让网络聚焦 |

**两者不是一回事**，但经常一起用（ResNet + SE、ResNet + CA）。

> 本文就是：**ResNet 残差通路**（保证 S2 特征质量）+ **注意力加权**（CFFM、MFAM）。
> 这两个机制分别对应"能不能学"和"学什么"。

---

## 5.6 选型速查

| 需求 | 选什么 |
|---|---|
| 只要通道重要性，不要位置 | SE（最轻） |
| 通道重要性 + 位置信息 | **CA / Coordinate Attention** |
| 方向性结构（杆、长条、道路） | **Strip Pooling / 条带卷积** |
| 通道+空间都要，且轻量 | ECA + 空间注意力分开做（本文 CFFM） |
| 全局建模、不想手写结构 | Transformer / Swin |
| 计算预算紧 | ECA、1×1 替代 MLP |

## 5.7 自测题

1. **SE 和 CBAM 的区别是什么？**CBAM 的两个注意力是串联还是并联？
2. **SE 的"挤压"操作丢掉了什么信息？**Coordinate Attention 是怎么把它找回来的？
3. **Strip Pooling 为什么用 1×h 和 h×1 两种条带？**分别擅长发现什么？
4. **本文的 MFAM 用了 CA 和 SP 的思路，但论文全文没有引用这两篇。**这件事在学术上意味着什么？该怎么做？
5. 残差连接和注意力机制，分别在解决"什么"层面的问题？

<details>
<summary>👉 自测答案</summary>

**1.**
- SE：只做**通道**注意力，权重由全局池化 + MLP 产生。
- CBAM：**通道 + 空间**两个注意力模块，**串联**（先通道后空间），可插到任意 CNN 里。

**2.** SE 的 squeeze（全局平均池化）把空间维压成 1×1，**丢掉了"哪里"的信息** —— 只能说"边缘通道重要"，不能说"图像左上角重要"。
CA 的做法：**分别沿 H 和 W 方向池化**（不是全压成 1×1），把两个方向的位置信息保留下来，再拼接做 1×1 卷积生成通道权重。

**3.**
- **1×(h−1) 水平条带**：沿 W 方向聚合每一**行** → 保留**水平**方向的上下文 → 擅长发现**竖直的杆/柱**
- **(w−1)×1 垂直条带**：沿 H 方向聚合每一**列** → 保留**垂直**方向的上下文 → 擅长发现**水平的长条**（道路边界、屋檐）

UAV 场景里车辆是长条形的，雾中远车只剩淡影，所以方向性结构特别有用。

**4.** 学术上这叫**"未标注的借鉴"**——方法确实来自那两篇，但论文没引用，属于**引用规范问题**。
读者（和审稿人）会怀疑作者是否理解前人工作，或者是否回避了对比。
**正确做法**：要么补上引用并在文中说明"借鉴 CA 的位置编码思路"和"借鉴 SP 的条带建模"，要么明确说明"我们独立提出并重新设计"，并做消融证明差异。

**5.**
- **残差连接**解决的是"**能不能学到**"（可优化性 / 梯度通路 / 退化问题）
- **注意力**解决的是"**学什么、聚焦哪里**"（特征选择 / 空间加权）
前者是**结构层面的连接方式**，后者是**特征层面的重新加权**。

</details>
