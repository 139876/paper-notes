## 三个"低成本高回报"的补充实验

### ① 补齐 AP_small / AP_medium / AP_large

**为什么值得做**：论文把"尺度变化"列为三大核心动机之一，却**只报了 mAP@[.5:.95]，没报分尺度指标**。读者因此**无法验证 MFAM 是否真的改善了尺度适应**。

```python
# mmdet 评测时开启面积分档
data_evaluator = COCOEvaluator(ann_file, iou_types=['bbox'], use_area=True)
# 或者直接用 pycocotools 的 areaRng
```

**预期**：MFAM 的增益应主要落在 **AP_small**（因为它针对的是"又小又糊"的目标）。如果增益均匀分布在三个尺度上，那"多尺度"的设计动机就有点站不住。

**成本**：改一行配置 + 重跑 eval。**5 分钟的事，却能验证或推翻论文的核心主张之一。**

---

### ② F_clean detach 消融

**要检验的命题**：L_dh 的梯度到底有没有在塑造 F_clean？

```python
# 在 CFFM 入口处
F_clean = F_clean.detach()   # 切断 L_dh → 检测 的梯度路径
```

| 结果 | 结论 |
|---|---|
| mAP 明显下降 | L_dh 确实在塑造 F_clean，λ = 0.5 的结论成立 |
| mAP 几乎不变 | 去雾监督是多余的，论文的"跨域协作"叙事需要重新审视 |

**成本**：加一行 `.detach()` + 重训。**这是本工作最锋利的批评性实验。**

---

### ③ 按目标距离/面积分桶统计 CCDD 的增益

**要检验的命题**：CCDD 能否恢复被雾"深度混合"掉的信息？

```
  按 GT 面积把 HazyDet 测试集分桶:  <32² / 32²-96² / >96²
  分别统计: 基线 mAP  vs  CCFA-Net mAP

  预期 (若物理约束成立):
     小目标 (远景, t 最小) 增益应显著小于大目标
     → 证明「信息论上不可逆」这条论断

  若增益不随距离衰减:
     → 说明 CCDD 学到了比物理模型更强的东西, 那是个更值得讲的故事
```

## 实验设计的三层规范（可直接套用）

| 层次 | 问的问题 | 论文中的对应 |
|---|---|---|
| **模块组合（2^3 全排列）** | 每个模块贡献多少？合起来有没有协同？ | 表 8 |
| **内部替换** | 我的设计与最接近的竞品在同一位置比，谁更好？ | 表 10（CFFM）、表 11（MFAM） |
| **同框架替换赛** | 把我的模块塞进中立框架，与其他人的模块公平对比 | 表 12（FPN-MFAM vs FPN-DSAM/DPIC/CFPT） |

> [!tip] 表 12 尤其漂亮
> 它把 MFAM 塞进一个**中立的 FPN 框架**里，和 DSAM / DPIC / CFPT 公平对比，避免了"我用我的方法，你用你的方法"的不公平比较。
> **这是你以后做消融时应该模仿的写法。**
