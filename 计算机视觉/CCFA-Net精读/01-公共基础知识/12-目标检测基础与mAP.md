# 公共基础 12 · 目标检测基础与 mAP

> [!note] 这是**公共基础知识**
> 这篇笔记与 CCFA-Net **没有绑定关系** —— 换任何论文、任何项目都用得上。
> 读 CCFA-Net 时它是「地基」；不读这篇论文，它照样是一篇独立的基础课。

## 12.1 一句话定义

> **目标检测 = 给一张图，回答"哪里有什么、有多确定、框得多准"。**
> 输出是一堆 **框 (bbox) + 类别 + 置信度**。

分类只说"这是什么"；检测还要说"**在哪里**"；分割更进一步，逐像素给标签。

---

## 12.2 检测器的分类学（2026 视角）

### 经典两分法：按"要不要先出候选框"

| 类型 | 流程 | 代表 | 特点 |
|---|---|---|---|
| **两阶段 (two-stage)** | 先出候选框 → 每框单独分类+回归 | R-CNN / Fast / Faster R-CNN | 精度高、慢 |
| **单阶段 (one-stage)** | 一次前向直接出所有框 | YOLO、SSD、RetinaNet、FCOS、**TOOD** | 快、适合实时/无人机 |

> 这是**教科书级标准描述**，绝大多数综述都这么写。读论文时看到"the one-stage detector"就指右边。

### ⚠️ 但这个二分类已经不够用了 —— 三个必须知道的更新

#### ① 「单阶段 = 密集抽样 + 不同长宽比」是 anchor-based 时代的画像

| | 做法 | 代表 |
|---|---|---|
| **Anchor-based** | 预先在特征图上放一堆**不同宽高比**的锚框，网络预测**相对偏移** | YOLOv1–v7、SSD、RetinaNet、**Faster R-CNN 的 RPN** |
| **Anchor-free** | **不放锚框**，每个位置直接预测**中心点 + 到四条边的距离**，再从距离反解出框 | FCOS、CenterNet、**TOOD**、YOLOv8 的 anchor-free 分支 |

> **密集预测还在，但"不同长宽比抽样"这一半已经过时。**
> 本文用的 TOOD 是 **anchor-free 单阶段** —— 官方仓库的检测头文件就叫 `fcos_DeCoDetHead.py`。

#### ② 「单阶段精度低」已经不是固有缺陷

经典说法是"正负样本极不平衡 → 精度稍低"。但这在 2017 年前成立，**后来被解决了**：

| 时间 | 进展 | 效果 |
|---|---|---|
| ~2015 | 单阶段精度明显低于两阶段 | 差距 8~10 mAP |
| 2017 | **Focal Loss**（Lin et al.）+ **RetinaNet** | 单阶段 AP 首次追平两阶段 |
| 2019+ | **样本分配策略**赛道：ATSS、**TOOD 的 TAL**、SimOTA | 差距进一步缩小 |

> 🎯 **准确的说法**：不是"单阶段精度低"，而是"**没解决好正负样本（和正样本内部）怎么分配**"。
> 这正是 **TOOD 的 TAL** 要解决的问题，也是本文选它的理由。

#### ③ 还有第三类：Transformer 集合预测（set prediction）

DETR / Deformable DETR / DINO / RT-DETR —— **既不是两阶段也不是单阶段**。

核心机制：**匈牙利匹配 + 一对一正样本分配**，天然**不需要 NMS**。

> 现在更常见的分法是 **anchor-based / anchor-free**，或 **NMS-based / NMS-free**。

### 检测器谱系表（本文的位置）

| 检测器 | 类型 | anchor | 样本分配 | 与本文关系 |
|---|---|---|---|---|
| Faster R-CNN | 两阶段 | anchor-based | RPN | 相关工作 baseline |
| YOLO 系列 | 单阶段 | anchor-based（v8 起有 anchor-free 分支） | — | 相关工作 |
| RetinaNet | 单阶段 | anchor-based | Focal Loss | — |
| FCOS | 单阶段 | **anchor-free** | — | 本文官方代码沿用其头 |
| **TOOD** | **单阶段** | **anchor-free** | **TAL** | ✅ **本文检测头** |
| DETR 系 | **集合预测** | anchor-free | 匈牙利一对一匹配 | — |

> [!note] 本文检测头的具体配置
> TOOD 是在 FCOS 基础上加了**层注意力**和**预测对齐**（结构），再配上 **TAL**（训练策略）。
> 细节见 [[09-第8讲-TOOD检测头精讲]]。

### 一句话记住三个关键词

> **单阶段 = 快；anchor-free = 少超参；TAL = 把"分类好"和"定位准"的框挑出来当正样本。**

## 12.3 交并比 IoU：所有检测评价的基础

$$
\mathrm{IoU} = \frac{\text{交集面积}}{\text{并集面积}}
$$

> 🎯 **比喻**：两个框的 IoU = "两人握手的面积 ÷ 两人站一起占的面积"。
> 重叠越多，IoU 越大。

| IoU 值 | 含义 |
|---|---|
| 0 | 完全不重叠 |
| 0.5 | 论文判定"命中"的常见阈值（VOC 口径） |
| 0.75 | COCO 里算"高标准命中" |
| 1.0 | 完全重合 |

**IoU 系回归损失**（检测框回归的标准做法）：

| 损失 | 思路 |
|---|---|
| **IoU Loss** | 直接优化 `1 − IoU` |
| **GIoU / DIoU / CIoU** | 在 IoU 基础上补充"中心点距离""宽高比"等几何项 |

## 12.4 NMS：怎么把重复框去掉

同一个目标可能产生十几个重叠框。**非极大值抑制 (NMS)** 的规则：

1. 按置信度从高到低排序；
2. 拿走分数最高的框；
3. 把所有与它的 **IoU > 阈值**（常用 0.5~0.7）的框**抑制**（删掉）；
4. 重复。

> 🎯 **比喻**：选秀 —— "分最高的先留下，凡是和他重合度超过标准的其他选手，全部淘汰。"

**注意**：NMS 是**不可微**的。所以 TOOD 不用 NMS 做样本分配，而是用**可微的 TAL**（见 [[09-第8讲-TOOD检测头精讲]]）。

## 12.5 AP 与 mAP：从框到分数

### 一步步来

1. **TP / FP / FN**：按置信度排序后逐个判定（与 GT 的 IoU 超过阈值且类别正确 = TP）
2. **Precision** = TP / (TP + FP) —— "我报的里面有多少是对的"
3. **Recall** = TP / (TP + FN) —— "真的里面我找到了多少"
4. 把 (Recall, Precision) 画成曲线 → **PR 曲线**
5. **AP** = PR 曲线下的面积（对所有类别、所有 Recall 点取平均）
6. **mAP** = 所有类别 AP 的平均

$$
\text{AP} = \int_0^1 P(R)\, dR \quad\text{（连续版，VOC2010+ 用 11 点插值）}
$$

> [!important] 一句话记住
> **AP 衡量"又快又准"**：召回要全（不漏），在保证召回的前提下精度要高（不乱报）。
> 所以 **NMS 的 IoU 阈值、置信度阈值都会直接改 AP**。

### mAP 的三种口径（**最容易踩坑的地方**）

| 口径 | IoU 阈值 | 说明 |
|---|---|---|
| **VOC2007** | 0.5 | 最宽松，早期用 |
| **VOC2010+** | 0.5 | AP 用连续积分，更严格 |
| **COCO** | **0.50 → 0.95，步长 0.05** | 取 10 个 IoU 阈值的平均 |

$$
\text{mAP}_{\text{COCO}} = \frac{1}{10}\sum_{t \in \{0.50, 0.55, \dots, 0.95\}} \text{AP}_{IoU=t}
$$

> [!warning] 本文用的是 COCO 口径（很严格）
> 本文报的 **mAP = 54.6**，是 **IoU 0.50:0.05:0.95 的平均**，不是"IoU=0.5 的 AP"。
> 这意味着**定位精度必须到 0.9 级别才能拿满分**。
> 对照：TOOD 官方在 COCO 上报的 42.5（ResNet-50）也是这个口径。
> **不同口径的数字绝对不能横向比较** —— 这是读论文表格时最常见的错误之一。

## 12.6 尺度问题：小目标与大目标

遥感/UAV 图像的典型困难：

| 尺度 | 像素尺寸（本文 HazyDet） | 难点 |
|---|---|---|
| **小目标 (small)** | 面积 < 32² | 下采样几层后就没了；IoU 对偏移极敏感 |
| 中目标 (medium) | 32² ~ 96² | — |
| **大目标 (large)** | 面积 > 96² | 反而在浅层分辨率下更糊 |

> [!important] 本文的一个可改进点
> 论文**没有报告 AP_small / AP_medium / AP_large**（COCO 标准会拆开报）。
> 而 UAV 场景恰恰是**小目标为主**（车在高空画面里很小）。
> 所以"54.6 这个数到底在小目标上表现如何"是**未知**的 —— 这是本论文的软肋之一，见 [[13-第12讲-批判性评价与可做选题]]。

## 12.7 本文（CCFA-Net）的检测侧配置速览

| 项 | 值 |
|---|---|
| 检测器 | TOOD（单阶段、锚框自由） |
| 骨干 | ResNet-50（ImageNet 预训练，**部分冻结**） |
| Neck | FPN，`in_channels=[256,512,1024,2048]`，`out_channels=256`，`start_level=1`，`num_outs=5` |
| 特征层 | P3~P7，stride = 8, 16, 32, 64, 128 |
| 样本分配 | TAL（Task-aligned），γ=6 |
| 损失 | 分类（Focal/CE）+ 定位（IoU 系） |
| 指标 | mAP@0.50:0.95（COCO 口径） |
| 输入尺寸 | 1333 × 800 |

> [!tip] 为什么记住 FPN 这几个数
> `start_level=1` 意味着**从 C3 开始**（stride 8），**C2（stride 4）不进 FPN**，它只喂给 CCDD 做去雾。
> 这个设计正好呼应本文的核心主张：**浅层交给去雾，深层交给检测。**

## 12.8 常见误解

| 误解 | 正解 |
|---|---|
| mAP = 准确率 (accuracy) | 完全不同。mAP 对**所有召回水平**取平均，且**分类和定位都算在内**。 |
| IoU 阈值 0.5 和 0.95 只是"松一点严一点" | 在 COCO 口径下，阈值 0.95 要求框**几乎完全重合**，能区分出"框得糙"和"框得准"的模型。 |
| Anchor-free 一定比 Anchor-based 好 | 不一定。Anchor-free 少了一组超参，但早期精度常低于 anchor-based；TOOD/FCOS 用其他手段补上了。 |
| 单阶段精度天生不如两阶段 | **过时了**。Focal Loss（2017）之后早就追平；现在差距主要在样本分配策略，不在「单阶段」这个标签本身。 |
| NMS 可以直接用（它不是可导的吗） | NMS **本身不可微**，所以不能用它做端到端训练。TOOD 用可微的 TAL 替代。 |
| COCO 口径的 mAP 和 VOC 口径能比 | **不能**。本文 54.6 是 COCO 口径；HazyDet 官方仓库里 TOOD 报的 51.4 也是 COCO 口径，才可以比。 |
| 报了 mAP 就够了 | 不够。要同时报 **小/中/大目标**、**各类别 AP**、**真实雾与合成雾**的表现，本文只报了两套数据的总 mAP。 |

## 12.9 自测题

1. IoU 是什么？IoU=0.5 和 IoU=0.95 分别意味着什么？
2. NMS 的四步是什么？为什么 NMS 不能用在端到端训练里？
3. AP 和 mAP 的关系是什么？
4. **本文报的 54.6 是哪种口径？** 换成 VOC 口径会变成什么样（定性即可）？
5. 本文 FPN 的 `start_level=1` 意味着什么？和"浅层交给去雾、深层交给检测"的主张怎么对上？
6. 为什么说本文没报 AP_small 是个问题？

<details>
<summary>👉 自测答案</summary>

**1.** IoU = 交集面积 / 并集面积。0.5 表示"重叠一半"，是 VOC 判定命中的门槛；0.95 表示几乎完全重合，要求框的位置和大小都非常准。

**2.** ①按置信度降序 ②取最高分框 ③抑制所有与它 IoU 超过阈值的框 ④重复。
**不可微**是因为"取最大""抑制"是硬性选择（argmax / 阈值判断），梯度无法穿过。所以端到端训练要用可微替代（TOOD 的 TAL）。

**3.** AP = 单个类别的 PR 曲线下面积；mAP = 所有类别 AP 的平均。

**4.** **COCO 口径：IoU 从 0.50 到 0.95，步长 0.05，取 10 个阈值的平均**。
换成 VOC 单阈值 0.5，数值会**明显偏高**（因为门槛放宽），但这个数**不能和论文的 54.6 并列比较**，必须换算到同一口径。

**5.** `start_level=1` 表示 FPN **从 C3（stride 8）开始**，C2（stride 4）**不进 FPN**。C2 只被送进 CCDD 做去雾；C3/C4/C5 送进 FPN 生成 P3~P7 给检测头。→ 正好是"浅层归去雾、深层归检测"的物理落实。

**6.** UAV 高空画面里车是**小目标**。COCO 口径的 mAP 把大小目标混在一起平均，**大目标的高分可以掩盖小目标的低分**。不报 AP_small，就无法判断这个方法究竟有没有真的解决了 UAV 的核心难题（小目标 + 前景模糊 + 尺度剧变）。**这是选题时第一个该补的实验。**

</details>
