## 7.1 数据集：DroneVehicle

> **出处**：Sun et al., *Drone-based RGB-infrared cross-modality vehicle detection via uncertainty-aware learning*, IEEE T-ITS 2022（本文引用为 [7]）

| 项目 | 数值 |
|---|---|
| 图像对总数 | **28,439 对** IR-RGB |
| 训练 / 测试 | 17,990 / 10,449 对 |
| 类别 | car、truck、bus、van、freight car（**5 类**） |
| 拍摄角度 | 15°、30°、45°、90° |
| 飞行高度 | 80 m、100 m、120 m |
| 光照条件 | 白天、夜晚、**暗夜** |

> [!note] 为什么用 DroneVehicle？
> 因为它是**配对**的（同一场景同时拍 IR 和 RGB），跨模态蒸馏需要这种配对关系。
> 这一点是本文的**隐含前提**——现实中未必总有这么干净的数据 → 见 [[paper-notes/计算机视觉/Cross-Modal-UAV精读/09-第8讲-批判性评价与可做选题]] 方向 2。

## 7.3 参与对比的基线（这里有个方法论细节）

论文挑了 **9 个只用 RGB 的旋转框检测器**做对比：

> RRLN、RRPN、FA-FPN、ROI-Transformer、SCRDet、Gliding-Vertex、CenterMap、S2A-Net、ReDet
> 外加 **Oriented R-CNN** 作为**同结构基线**

> [!important] 为什么必须只比 RGB-only？
> 因为本文推理时也是纯 RGB，**必须同条件比**。
> 如果拿一个 RGB-only 方法去和"推理需要双模态"的方法比精度，那是耍赖。

另外自建了一个**真正的多模态基线**：把 RGB Oriented R-CNN 和 IR Oriented R-CNN 的预测结果做**后处理融合**（交叉 IoU > 0.5 的框合并、概率相加）。

## 7.5 三个关键读数

### ① 比同结构单模态基线高 4.6 个点

56.1 → **60.7**，而且**全面超过 Table III 里所有 11 个 RGB-only 基线**（最强对手 ReDet 55.6）。

> ⚠️ 读表提醒：**对表里其他方法的比较要打折扣**——它们用的是不同 backbone（多数是 ResNet50 + 不同 FPN 变体），并非同一套基线。
> **最干净的对比是最后三行**：Oriented-RCNN / Oriented-RCNN 多模态 / Ours，三者**同结构同 backbone**。

### ② 逼近真正的多模态模型

多模态（RGB+IR，参数量 2 倍 + 需要红外相机）= 63.2，本文 = 60.7，**只差 2.5 个点**。

> 🎯 **类比**
> 多模态方案相当于"**两个人一起看同一块黑板**"，效率高但要占两个工位。
> 本文相当于"**一个人看一块黑板，但被训练过怎么在暗处也能看**"。
> **一个人干两个人的活，效率打了点折，但省下了一整个工位。**

### ③ 分类别增益非常有意思

| 类别 | 基线 | 本文 | 增益 |
|---|---|---|---|
| Car | 79.4 | 82.9 | +3.5 |
| **Freight Car（货车）** | 33.2 | 39.2 | **+6.0** |
| Truck | 51.4 | 51.9 | **+0.5** |
| Bus | 87.0 | 89.0 | +2.0 |
| **Van（厢式车）** | 35.8 | 42.4 | **+6.6** |

**为什么货车和厢式车收益最大，而卡车几乎没提升？**

- 货车、厢式车**又长又暗**，在夜里 RGB 几乎完全看不到轮廓 → **红外正好补的就是这个** → 收益最大
- 卡车（Truck）本身**体积大、特征明显**，RGB 学生本来就学得不错，**老师没什么可教的** → 提升只有 0.5

> [!success] 这说明什么？
> **CKD 的价值集中在"RGB 看不见的类别"上**——完全符合直觉，也说明模型学到的不是噪声。
> 这条规律可以直接指导后续工作：**增益应该正比于"该类别在 RGB 下的不可见程度"**。

## 7.6 把主结果翻译成工程语言

| | 本文方案 | 真正多模态 |
|---|---|---|
| 推理 mAP | 60.7 | 63.2 |
| **部署 mAP** | **60.7** | 63.2 |
| 参数量 | **40M** | 80M |
| 红外相机 | **不需要** | 需要（> 5000 美元） |
| 推理前向 | **1 次** | 2 次 |
| 机载功耗 | **1 份** | 2 份 |

> **用 2.5 个 mAP 点，换掉一整套传感器 + 一半算力。**
> 在批量部署的无人机业务里，这个交换通常是**压倒性划算**的。
